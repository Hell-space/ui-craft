# Kiln 组件样张 · 设计笔记

产品：**Kiln** —— 给小型陶艺工作室用的窑炉排程与批次追踪工具（排烧制、追踪每层棚板上的作品、通知会员取件）。

## 模型

Opus 5.5，模型 ID：`claude-opus-5-5`。

## 设计立场

方向是"安静的工具，带一点材料感"。用户是工作室经理和陶艺老师，他们每天对着表格做排程，所以界面主体必须是密、稳、可扫读的工具界面；但这个行业本身有很强的物质性（泥、釉、火），我让这种物质性只出现在三个地方：暖色的素坯色中性灰、以釉色命名并取色的状态色、以及衬线体用于标题和大数字。其余一律克制。

- 唯一饱和的颜色是钴蓝（cobalt glaze），专门表示"这里可以操作"——主按钮、焦点、选中。陶土红（terracotta）只是品牌与"窑正在烧"的实时数据色，不承担交互语义，这样红色系不会和危险色打架。
- 样张本身也按产品界面的规矩来排：左侧编号目录、每节"编号 + 衬线标题 + 一段说明为什么这样做"，像一份真正的设计系统文档，而不是展示页。

考虑过又放弃的：
- **全暗色"窑火"主题**（黑底橙光）：好看但太戏剧化，白天的工作室里用起来累，而且橙色会和警告色冲突。
- **纯中性 Linear/Vercel 式灰白**：稳妥但没有身份，换任何产品名都成立，这正是我想避免的。
- **陶土色做主操作色**：最"切题"，但它离危险红太近（色相 40 vs 27），在按钮矩阵里主按钮和危险按钮会难以区分，放弃。

## 字体

- **Newsreader**（衬线，400/500，启用光学尺寸）：页面标题、节标题、卡片大读数（1,186 °C）、空状态标题。用途是"有声音的时刻"。选它是因为光学尺寸让 24px 时扎实、44px 时舒展，且数字是好看的衬线等高数字。回退：Iowan Old Style → Palatino → Georgia → 宋体。
- **Instrument Sans**（无衬线，400–700）：全部界面文字。比 Inter 略窄、字形更有个性（a、g、R），在 13–14px 的密集表格里依然清楚。回退：系统 UI 字体 → Segoe UI → Helvetica → PingFang SC / 微软雅黑。
- **JetBrains Mono**（400/500）：ID（F-2291）、测温锥（^6）、时间戳、overline 小标签。凡是需要逐位比对或复制的东西都用等宽。回退：SF Mono → Cascadia Mono → Consolas。
- **中文**：不加载网络中文字体（太大），走系统栈 PingFang SC → Hiragino Sans GB → Noto Sans SC → 思源黑体 → 微软雅黑；字体栈把 Instrument Sans 放在前面，所以中文里的数字与拉丁字母仍用 Instrument Sans，"1,222 °C"中英文环境下长得一样。

字号阶梯（size/line-height · 字距）：
| token | 字体/字重 | 值 |
|---|---|---|
| display | Newsreader 400 | 44/48 · −2.2% |
| title | Newsreader 400 | 32/36 · −1.5% |
| heading | Instrument 600 | 20/28 · −1.2% |
| subheading | Instrument 600 | 16/24 · −0.6% |
| body-lg | Instrument 400 | 16/26 · 0 |
| body | Instrument 400 | 14/20 · 0（默认正文） |
| label | Instrument 500 | 13/18 · 0 |
| caption | Instrument 400 | 12/16 · +0.5% |
| mono | JetBrains 400 | 12/16 · 0 |
| overline | JetBrains 500 | 11/16 · +6% · 全大写 |

样张首页大标题用 48/52。行高全部落在 4px 网格上。大字收紧字距、小字微放，是光学补偿。

## 色彩

全部用 OKLCH 定义，中性色带色相 55–80 的极低彩度（0.006–0.014），即"素坯色"。

**浅色（Bisque）**
- `--bg` oklch(0.975 0.006 80) 页面底色
- `--surface` oklch(0.995 0.002 80) 卡片/输入框/对话框
- `--surface-2` oklch(0.958 0.008 78) hover、表头
- `--sunken` oklch(0.945 0.009 76) 禁用底、凹槽
- `--line` oklch(0.895 0.010 72) 分隔线；`--line-strong` oklch(0.80 0.012 70) 控件边框
- `--text` oklch(0.235 0.014 55) 正文（天目釉色）；`--text-2` oklch(0.43 …) 次要；`--text-3` oklch(0.565 …) 占位/元信息
- `--accent` 钴蓝 oklch(0.475 0.150 262)，hover 0.425，按下 0.385，浅底 oklch(0.945 0.025 262)
- `--clay` 陶土 oklch(0.60 0.105 45)
- `--ok` 青瓷 oklch(0.52 0.090 165)；`--warn` 赭石 oklch(0.56 0.115 72)（文字用）与 `--warn-fill` oklch(0.78 0.140 78)（填充用）分开；`--danger` 铁红 oklch(0.53 0.185 27)
- 状态色的文字版明度都在 0.52–0.56，保证在各自浅底上都过 4.5:1，也让它们视觉重量相当。

**深色（Reduction，还原烧）**
- `--bg` oklch(0.175 0.008 60)，`--surface` 0.212，`--surface-2` 0.245，`--sunken` 0.155（比底更深）
- `--line` 0.295，`--line-strong` 0.385
- `--text` oklch(0.935 0.008 78)，`--text-2` 0.765，`--text-3` 0.615
- `--accent` oklch(0.735 0.120 262)，深色模式主按钮是"浅蓝底 + 深字"，而不是把浅色版的深蓝原样搬过来（深蓝在深底上对比不够）
- 状态色提亮到 L≈0.70–0.82、降彩度；浅底变成 L≈0.28 的有色深底
- 深色下阴影几乎不可见，层级主要靠表面明度递增（bg < surface < surface-2）和 1px 边框表达。

## 构图与间距

- 4px 基础单位，常用 4/8/12/16/20/24/32/48/64/96。
- 页面：最大宽 1240，左 200px 固定目录 + 48px 间隙 + 内容列。≤1020px 隐藏目录，≤720px 全部单列、16px 边距。
- 每节头部是 1 : 1.25 的两栏：左边编号+标题，右边一段说明，底对齐，使说明文字和标题基线在视觉上咬合。
- 节与节之间 48px + 1px 分隔线；面板内 24px 内边距；面板之间 16px。
- 按钮状态做成真正的"层级 × 状态"矩阵表格，行是层级、列是状态，一眼就能做竖向（同一状态下层级区分是否够）和横向（同一层级状态变化是否清楚）的比较。
- 左对齐为主，只有数字列右对齐，空状态居中。

## 几何、深度与质感

- 圆角：4（小标签、listbox 项）/ 6（按钮、输入框）/ 8（大按钮、listbox、toast）/ 12（面板、卡片）/ 14（对话框）/ 999（徽章、开关）。原则是外层容器圆角 ≥ 内层，对话框最大因为它浮得最高。
- 边框：所有容器都有 1px 边框，阴影只是辅助；这样深色模式下层级依然成立。
- 阴影三级：shadow-1（静止卡片，近乎贴地）、shadow-2（悬停卡片、listbox、toast）、shadow-3（对话框，多层叠加，大模糊带负扩散）。阴影色带暖色相，不是纯黑。
- 主按钮有 1px 内高光（inset 白 14%），给一点釉面感但不做渐变。
- 纹理：全页叠一层 SVG feTurbulence 噪点，浅色 3.5%、深色 5% 不透明度，像素坯纸面，几乎察觉不到但让大色块不"塑料"。
- 卡片里的釉料小方块用径向渐变画出釉面流动感，不用图片。

## 组件规格

- **按钮**：高 28/36/44，内边距 10/14/18，字号 13/14/15，字重 500，圆角 6（大号 8），图标 14/16，图标与文字间距 4–6。36 是默认，因为 14px 正文配 36 控件是桌面工具的舒适密度；44 留给移动端和空状态主行动。
- **按钮层级**：Primary（钴蓝实底）/ Secondary（白底 + 强边框 + 轻阴影）/ Tertiary（透明，hover 才出底）/ Destructive（铁红实底）/ Link（钴蓝文字，hover 下划线 offset 3px）。
- **按钮状态**：hover 换深一级底色；pressed 再深一级并下沉 0.5px；focus 是 2px 底色间隔 + 2px 焦点色双环；loading 保留宽度、换为旋转环 + 现在进行时文案（"Starting…"）；disabled 统一成凹槽底 + ash 文字，不用 opacity，避免在不同底色上颜色不可预测。
- **输入框**：高 36，水平内边距 12，边框 1px line-strong，圆角 6，内含 1px 极淡内阴影；聚焦时边框变钴蓝 + 3px 26% 透明光晕；错误时边框铁红、提示文字变红并带图标；禁用时凹槽底、边框变弱。标签 13/500 在上，间距 6，提示 12/16。
- **Select**：闭合态是原生 select（免费获得键盘与移动端行为），右侧自绘 chevron；展开态的 listbox 静态绘制：4px 内边距、项高 32、分组标题用 mono overline、右侧显示程序时长、选中项左侧对勾、不可选项变灰并写明原因。
- **复选/单选**：16px，与 20px 行高首行对齐（margin-top 2px），描述行 12/16。勾号用 CSS mask 绘制，状态切换有 120ms 缩放。
- **开关**：32×20 轨道，16px 圆钮，位移 12px，200ms。
- **Tabs**：高 44，间距 24，选中态 2px 钴蓝下划线压住容器底线；计数小胶囊在选中时同步变色。
- **徽章**：高 22，全圆角，6px 圆点 + 文字；方形标签版高 20，mono 11px，用于 ^6 这类代码。
- **表格**：表头 36 高、12px/500 灰字、surface-2 底；行高 48；只有横线；ID 用 mono 放在名称下方作副行；数字列右对齐 + tabular-nums；选中行钴蓝浅底 + 左侧 2px 竖条；工具栏控件统一 28/32 高。
- **卡片**：圆角 12，头部 20px 内边距，正文 16/20，底部操作区带分隔线和更浅的底。只有可点击卡片才有 hover 抬升。
- **对话框**：宽 440，圆角 14，24px 内边距，左侧 36px 危险图标圆，正文与标题左对齐于图标右侧；按钮右对齐，危险按钮在最右且重复动词（"Abort firing"），取消按钮写成"Keep firing"而不是"Cancel"。
- **Toast**：宽 380，圆角 8，图标 20，标题 14/500，副文 13；浅色模式下成功 toast 用反色（深底）以从页面中跳出来。

## 动效与交互状态

- 时长只有两档：120ms（颜色、边框、阴影）和 200ms（开关滑动、卡片抬升、主题切换）；曲线统一 cubic-bezier(.2,.8,.2,1) 的 ease-out。
- Toast：260ms 上移 8px + 0.98 缩放入场，180ms ease-in 退场；底部 2px 进度条线性消耗 5 秒；鼠标悬停或键盘聚焦时暂停计时；最多同时 3 条。
- "烧制中"徽章的圆点有一个 1.8s 的扩散脉冲——全页唯一的循环动画，只给真正"正在发生"的东西。
- 加载按钮用 0.7s 旋转环。
- 所有 hover/pressed/focus 都同时以静态类（.is-hover / .is-active / .is-focus）渲染在样张上，也都能真实交互。
- Tabs 支持左右方向键、Home/End，采用 roving tabindex。表格全选复选框会根据行选择自动变成半选态。
- 主题：首次按系统 prefers-color-scheme，切换后存 localStorage（try/catch 包裹），head 内联脚本在首屏前设置，避免闪烁。
- prefers-reduced-motion 下所有动画和过渡压到 1ms。

## 我在意的细节

1. 色板上的数值不是写死的，而是运行时从 CSS 变量读取，所以切到深色后显示的就是深色的真实值，文档不会和实现脱节。
2. 禁用态不用 opacity，而是明确的凹槽底 + 灰字，避免禁用按钮在不同背景上变成"半透明的蓝"。
3. 加载态按钮写的是进行时动词"Starting… / Saving…"，并保持宽度不跳。
4. 错误提示告诉人怎么修："Kiln B allows holds up to 90 min. Lower the hold or pick Kiln A."，而不是"Invalid value"。
5. 表格里的温度"1,000 / 1,222"右对齐 + 等宽数字，千位分隔符对齐成一列；故障行的峰值温度变灰，暗示没有达到。
6. 对话框里的取消按钮叫"Keep firing"，危险按钮重复动词；正文给出具体后果（1,186 °C、38 件、需要重烧）。
7. 复选框与多行标签对齐到首行，而不是垂直居中到整个标签块。
8. 下拉里不可选的选项写明原因"Kiln B can't reach"，而不是只灰掉。
9. 深色模式的主按钮和危险按钮改为"浅底深字"，不是简单反转。
10. 卡片里的温度曲线同时画了计划曲线（虚线）与实际曲线，当前点有光圈；面积只到"现在"为止。
11. 中文段落开启 `line-break: strict`、两端对齐、避头尾，中英数字之间加空格，引号用「」。
12. 赭石色拆成"文字用"和"填充用"两个值：黄色系做文字时必须更暗才过对比度，做填充时又必须更亮才像黄色。
13. 空状态插图画的是棚板上的试片，一块已经上了钴蓝釉、两块是虚线待填，和产品语义一致；还给了键盘快捷键提示。
14. 品牌标记是一个窑口剖面里的陶土色火焰，用 SVG 内联、跟随主题。

## 我刻意回避的做法

- 紫蓝渐变、玻璃拟态、大面积发光阴影、彩色渐变按钮。
- 用 Inter 做唯一字体、全中性灰——稳妥但没有身份。
- 用颜色单独表达状态（徽章都带文字和圆点）。
- 为每个状态发明新的颜色；整页只有一个饱和交互色。
- 把 placeholder 当 label；用"Cancel / OK"这种不说事的按钮文案。
- 用 emoji 或外部插画图库；用 Lorem ipsum。
- 卡片一律 hover 抬升（只有可点击的才抬）。
- 深色模式简单取反、用纯黑 #000 底。
- 装饰性动画（只保留"正在烧"的脉冲）。

## 这是"我"的习惯

大多数设计里我都会做的：
- OKLCH 定义颜色，中性色带一点点暖或冷的色相而不是纯灰。
- 一个饱和强调色 + 克制的状态色，状态色明度对齐。
- 4px 网格、14px/20 正文、36px 默认控件高、6–8–12 的圆角递进。
- 边框为主、阴影为辅，深色模式靠表面明度分层。
- 数字用 tabular-nums 右对齐，ID/代码用等宽字体。
- 双环焦点样式（底色间隔 + 焦点色）。
- 只有两档动效时长，ease-out。
- 文案具体、带数字、说后果。
- 衬线 + 无衬线 + 等宽的三字体组合（我很常用这个结构，虽然具体字体会换）。

只为这个题目做的：
- 素坯色中性灰、以釉命名的色板（Bisque、Celadon、Tenmoku、Iron red）。
- 钴蓝作为主色、陶土色作为品牌/实时数据色的分工。
- 纸面噪点纹理。
- 温度曲线卡片、试片空状态插图、窑口火焰标志。
- 样张式的"层级 × 状态"矩阵和编号目录（因为题目是 specimen sheet）。

# 风洞试验室

Claude Code 的 Opus 5.5 · 超高从空白写一页离线试验台。给它的是使用任务，外形、图形、数据口径、排印与布局由它决定。它没有使用生成图像。页面内的流线、三种壳体、通风孔、基准虚线与截面均以代码绘制。打开[原作](index.html)可以实际切换。

**第一稿。** 暗色试验段在浅色工作台里占据主视野，切换候选保持头模和观察角度。R0 是固定的上一代量产壳；三个试件按同一组风速比较阻力 N 和加热头模的散热 W。指标改善的方向各不相同。35 km/h 的闭合壳阻力 1.38 N，比初始基准低 12.1%，散热 11.6 W，也低了 32.2%。这组演示读数中的取舍可见，不宜把两个负号画成同一种好坏。

**实图返工。** 360×780 的首稿在第 367 像素可切风速，但两个绝对读数要分别滚到约第 964、1138 像素。与此同时，百分比在风速栏、方案卡和读数栏重复。Opus 读取夸克实拍的两张图，把唯一的主读数区并排接在风速条下，简化候选项，保留头盔描边、当前基准和比较尺。复看同尺寸，两组读数一起从第 318 像素出现，三种候选从第 477 像素出现，固定基准在第 627 像素。数字指对应区域顶边。[首稿和修稿](../../evals/evidence/wind-revision.webp)

**实际输入。** 在 1366、768、360、320 像素宽各走三外形 × 三风速，逐组核对两项数值。固定 S2 后切到 S3、50 km/h，阻力 3.54 N 的参照仍是 S2 的 2.94 N。刷新、重开同一文件、方向键换速度、数字切方案、设定与恢复基准均已验证。四种宽度的整页横向溢出均为零。 浅色和深色下都观察到烟线的帧间位移。切换减弱动效后烟线停止移动，改选格栅仍会更新阻力为 1.72 N（35 km/h）。无效的旧存储值会回到初始组合。

# 缓流器物 · 运营台首页 —— 设计笔记

## 模型

Opus 5.5（模型 ID：`claude-opus-5-5`）

## 设计立场

**"一份晨报，而不是一面监控墙。"**

使用者是运营负责人，每天早上打开一次，不是盯盘的人。她最需要的不是更多数字，而是三件事：昨天怎么样、我离目标还差多少、今天先做什么。所以首页的主角是一段**用人话写的摘要**（衬线大标题 + 一段正文），数字退到第二层去佐证这段话，图表退到第三层供追问。

设定的日期是 2026 年 11 月 10 日——双 11 前一天。我刻意把这个时间点放进内容里：倒计时、预售进度、尾款催付、爆款库存告急，这些让页面像一个真实早晨，而不是一张"任何一天都成立"的模板。

视觉上选了"温暖纸面 + 墨色 + 一点烘焙铜色"：和手冲器具这个品类（陶瓷、木柄、不锈钢、牛皮纸滤纸）的物质感一致，但克制到不变成咖啡馆装修。

考虑过又放弃的方向：
- **深色指挥中心风**（黑底霓虹、满屏大数字）：适合直播大屏，不适合早上用一杯咖啡的时间读完的场景，而且会把一家独立小品牌做得像券商。
- **重品牌化的咖啡色系**（棕色底、手写字体、咖啡豆插画）：讨巧但会侵蚀数据的可读性，后台每天看，装饰会很快变成噪音。
- **卡片网格 + 每个 KPI 一张卡**：最常见的后台样式。六个指标做成一条带分隔线的横带，比六张漂浮的卡更像"一行读完"的东西。
- **环形进度图表示年度目标**：环形无法同时表达"时间进度"这个对照物。改用一条横向进度条 + 一根铜色刻度表示时间进度，落后与否一眼可见。

## 字体

| 字体 | 用途 | 理由 |
|---|---|---|
| **Noto Serif SC**（600） | 问候标题、品牌名 | 给页面一个"晨报"式的人声开头；衬线中文在后台里少见，用一次就足够辨识。回退：Source Han Serif SC → Songti SC → STSong → SimSun |
| **Inter**（400/500/600） | 所有拉丁字符与数字 | 开启 `tnum` 等宽数字，表格和 KPI 纵向对齐；`cv11` 让单层 a 更安静 |
| **系统中文黑体** | 正文、标签 | PingFang SC → HarmonyOS Sans SC → Microsoft YaHei UI → Microsoft YaHei → Noto Sans SC。不加载中文无衬线网络字体，因为体积大、且各平台系统黑体已足够好 |

字号阶梯（px）：11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14（基准）/ 15 / 16 / 17 / 22 / 26 / 30。
- 30：问候标题（窄屏 24），行高 1.3，字距 0.01em
- 26：KPI 数值（窄屏 22），行高 1.2，字距 -0.025em
- 22：年度目标数，字距 -0.02em
- 15：卡片标题（600）与摘要正文，正文行高 1.75
- 14：基准，行高 1.6
- 12.5–13：表格与次级说明
- 11–11.5：标签、导航分组，导航分组字距 0.12em

数字一律负字距、等宽；中文正文不加负字距（中文本身字面饱满，收紧会挤）。单位符号 ¥ 和"单""%"缩小一号并变浅，让数字本体先被读到。

## 色彩

| Token | 浅色 | 深色 | 角色 |
|---|---|---|---|
| `--bg` | `#F5F3EE` | `#16130F` | 页面底，暖纸色，避免纯白的刺眼 |
| `--surface` | `#FFFEFB` | `#1E1A16` | 卡片面，比底色亮一档，靠明度差而不是阴影区分层级 |
| `--sunken` | `#EFECE5` | `#26211B` | 进度槽、分段控件底、缩略图底 |
| `--ink` | `#1E1A16` | `#EEE8DF` | 主文字、年度进度条（暖黑，不用纯黑） |
| `--ink-2` | `#57504A` | `#B8AFA3` | 次级文字 |
| `--ink-3` | `#8C847A` | `#857C71` | 说明、坐标轴 |
| `--line` | `#E4DFD6` | `#2F2A23` | 分隔线 |
| `--accent` | `#9A4A22` | `#D98A5E` | 烘焙铜色：今年曲线、最大渠道、最紧急待办、时间进度刻度 |
| `--compare` | `#B5ADA2` | `#5E564C` | 去年同期虚线 |
| `--up` | `#2F7350` | `#6CB98C` | 正向变化 |
| `--down` | `#B0362C` | `#E57B6F` | 负向变化、库存告急 |
| `--warn` | `#A86B12` | `#D9A24A` | 次一级预警 |

原则：整页只有一个强调色，它出现的地方就是"你该看这里"。涨跌色永远配 ▲▼ 符号，不让颜色单独承担含义。退款率下降用绿色——颜色表达的是"好坏"而不是"方向"。

## 构图与间距

- 外框：208px 侧栏 + 主区（最大 1260px，左右 40px 内边距），1440 宽下主区内容约 1150px。
- 主区内用 12 列栅格，间距 20px：趋势图 8 列 + 待办 4 列；下面三张 4 列卡；最后整宽商品表。
- 阅读顺序自上而下就是决策顺序：摘要 → 指标 → 趋势与待办 → 渠道/活动/口碑 → 商品明细。
- 首屏（1440×900）能看到摘要、年度进度、六个 KPI 和趋势图与待办的上半部分。
- 间距基于 4 的倍数：卡片内边距 20/24，KPI 内 18/20，列表行 12–13，段落间 8–16。
- 摘要正文限制 40em 宽，避免中文长行。
- 断点：1280 下 KPI 变 3×2；1100 下侧栏变为顶部横向导航、所有卡片堆叠、三张小卡变 2+1；720 下 KPI 变 2×3、内边距收到 16/18、表格容器内横向滚动（页面本身不横滚）。

## 几何、深度与质感

- 圆角：卡片 10px、控件 6px、标签 4px、进度条全圆。圆角小，偏"工具"而不是"App"。
- 边框：所有卡片 1px `--line` 实线，没有阴影。层级靠"纸色底 vs 更亮的卡面"表达。
- 唯一阴影：分段控件的选中态（1px 2px 的极浅投影 + 1px 描边），让它像一个被按下去的物理拨片。
- 趋势图下方用铜色 16%→0% 的竖向渐变面积，只为了让"今年"那条线有分量，去年的线保持干净的虚线。
- 网格线：0 轴实线，其余 2/3 虚线，比坐标数字更轻。
- 商品缩略图用 1.3px 线描的器具小图标（细口壶、滤杯、磨豆机、滤纸、秤、分享壶）而不是灰色占位块，线条风格与品牌标志一致。
- 品牌标志：墨色圆角方块中一个线描滤杯，下方一滴铜色——整页唯一的"装饰"。
- 不使用纹理、噪点、玻璃拟态。

## 动效与交互状态

- 趋势图：鼠标悬停出现十字线、空心点和深色提示框（显示日期星期、金额、去年同期与同比）；提示框靠近右边缘时自动翻到左侧。图表可以 Tab 聚焦，用左右方向键逐日移动。
- 14/30/90 天切换会重绘图表与底部三个汇总数字，没有动画——切换范围时数据应立即就位。
- 商品表：销量/成交额/可售天数三列可排序，当前排序列带铜色箭头；行悬停有极淡铜色底。
- 提示框淡入 120ms、上移 4px；导航与行悬停 120–150ms 的颜色过渡。没有入场动画、没有数字滚动。
- 倒计时每秒走动（以演示时间 08:40 为锚）。
- 按 `/` 聚焦搜索框。
- 所有交互元素有 `:focus-visible` 蓝色描边（独立于强调色，避免和"紧急"混淆）。
- 尊重 `prefers-reduced-motion`；跟随系统深色模式，并在切换时重绘 SVG（因为 SVG 颜色是读取 CSS 变量后写入的）。

## 我在意的细节

1. 年度进度条上用一根铜色竖刻度标"时间进度"，并直接写出"落后 ¥31 万"——比单独一个百分比更可行动。
2. 退款率"下降"标为绿色：颜色表示好坏，箭头表示方向，两者分开。
3. 每个 KPI 都写明对比基准（"较上周一"），而不是笼统的"环比"；周一对周一，避开星期效应。
4. 趋势图的去年同期"按星期对齐"，并在副标题里写明口径；"含预售定金"也写明。
5. 可售天数的定义直接写在表格副标题里（已扣预售锁定），否则这个数字会被误读。
6. 可售天数 < 4 天标红、4–7 天标琥珀，同时该商品的迷你走势线也变红，横向一眼能对上。
7. 渠道条形图以最大渠道为 100% 长度，而非占比，这样短渠道之间的差异也看得见；读屏文本里给出真实占比。
8. 待办不是"通知列表"，每条都写了原因和建议动作（例如"建议今天下单并把发货时间改为 11 月 20 日前"），并按影响排序。
9. 摘要里的数字都与下方模块一致（63,840 = 渠道之和；1,286 笔定金 = 双 11 卡片里的数字），没有自相矛盾。
10. 等宽数字 + 右对齐，表格里金额的个位对齐；¥ 符号缩小变浅。
11. 趋势图标注只标一个点（预售开启），并自动避让右边缘。
12. 用户评价原文照录，2 星评价与待办里的"包装破损"互相印证，物流评分 4.71 用红色——三处指向同一个问题。
13. 1440 下 KPI 六等分不换行；窄屏下分隔线按 2 列重排，不出现孤立的双线或缺线。

## 我刻意回避的做法

- 不做每个指标一张悬浮卡片 + 彩色图标圆底。
- 不用渐变背景、玻璃拟态、霓虹色、发光阴影。
- 不用饼图/环形图表示渠道构成或目标进度。
- 不用彩虹配色区分渠道；只有最大渠道用强调色。
- 不放没有对比基准的孤立数字。
- 不用"🔥""🚀"之类表情或"数据驾驶舱"式标语。
- 不做数字滚动、图表生长等入场动画——每天看的东西，动画第二天就是负担。
- 不用纯黑 #000 和纯白 #FFF。

## 这是"我"的习惯

大多数设计里都会做的：
- 一个强调色，其余全部是有温度的中性色；用明度差而不是阴影分层。
- 1px 细线 + 小圆角（6–10px）的"纸面"质感。
- 数字永远等宽、负字距、单位缩小变浅。
- 让文案承担信息设计的工作：标题说结论，副标题说口径。
- 涨跌必须带基准和符号，颜色不单独表意。
- 焦点样式、深色模式、减弱动效作为默认交付，而不是加分项。
- 表格优先于卡片堆叠来展示多维比较。

只为这个题目做的：
- 衬线中文问候标题和"晨报"式摘要段——因为使用场景是"每天早上一次"。
- 烘焙铜色作为强调色，暖纸底色——来自手冲器具的材料感。
- 双 11 前一天这个时间设定，以及倒计时、预售步骤条。
- 器具线描小图标和滤杯品牌标志。

## 如果再给我一倍时间

- 让摘要段由数据驱动生成（异常检测 → 选出最重要的 2–3 件事），而不是写死。
- 待办支持"已处理/稍后提醒"，处理后摘要随之改写。
- 趋势图加一个"按渠道堆叠"视图，并支持点选某天下钻到小时分布。
- 商品表加"预售锁定"列与补货在途数量，可售天数改为基于在途到货日期的预测曲线。
- 做一份打印/导出为晨会 PDF 的版式。
- 在真实设备上校对 Windows 下 Microsoft YaHei 与 Inter 的混排基线，必要时为中文单独调 `line-height` 与 `font-size-adjust`。
- 补充空状态、加载骨架、数据延迟告警（同步失败时顶部提示）。

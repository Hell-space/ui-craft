# 设计笔记 · The Machines That Knew the Sea

## 模型

Opus 5.5（模型 ID：`claude-opus-5-5`）

## 设计立场

题目选了"潮汐预报机"——开尔文勋爵的机械谐波合成器、美国的 Old Brass Brains、诺曼底登陆的潮汐表。选它是因为它天然需要两张"真正有信息"的图：一张解释"潮汐是若干正弦波之和"，一张解释"机器怎么用滑轮和一根钢丝做加法"。图不是装饰，而是文章论证的一部分，这样才能检验排版里文字与图的关系。

方向是**"安静的科学期刊 + 纸面感"**：暖白纸色、单一衬线正文、等宽字体只用于数据与标签、一个深海蓝作为唯一的主强调色，外加极少量的黄铜色（呼应机器的材质）。版式参照纸质刊物的边注体系（Tufte 式 sidenote），在宽屏上把注释放进右侧页边栏，让正文保持 66 字符左右的行长。

考虑过又放弃的：
- **大幅题图 / 全屏 hero**：没有真实图片，用 SVG 画一张"插画"会显得空洞；改为一条极细的、由真实潮汐公式算出的 14 天潮位线横贯全宽，作为标题与正文之间的分隔。
- **复古报纸风（多栏、黑体大标题、做旧纹理）**：容易变成戏仿，而且多栏在 375px 下无意义。
- **深色"科技感"配色**：题材是 19 世纪的黄铜与纸，深色主调会把它变成另一种东西。深色模式作为系统偏好跟随提供，但不是主设计。
- **衬线 + 无衬线标题的经典对比**：考虑过用 grotesk 做标签，最后选了等宽，因为这篇文章里的标签几乎都是"数据"（日期、天数、潮汐分量 M₂、表格时间），等宽更诚实。

## 字体

- **Newsreader**（Google Fonts，可变字体，含 opsz 6–72、wght 300–700、斜体）——正文、标题、引语、副标题全部用它。选它是因为它本身是为长篇新闻阅读设计的，有光学尺寸轴：标题用 opsz 72 时笔画对比更高、更紧，正文自动用小尺寸切面，同一家族就能撑起整个层级，不需要第二种衬线。
  - 回退栈：`"Iowan Old Style", "Palatino Linotype", Palatino, "Book Antiqua", Georgia, serif`——离线时在 macOS/iOS 落到 Iowan，Windows 落到 Palatino Linotype，都是体面的书籍衬线。
- **IBM Plex Mono**（400 / 500）——kicker、日期、阅读时长、小节编号、图内标注、表格、注释编号。全部配 `lining-nums tabular-nums`。
  - 回退栈：`ui-monospace, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace`。

## 色彩

浅色（默认）：
| 变量 | 值 | 角色 / 理由 |
|---|---|---|
| `--paper` | `#f5f1e8` | 背景。偏暖的纸色，降低大面积纯白的刺眼感，又不至于黄到像"做旧"。 |
| `--paper-2` | `#ece5d6` | 边栏底、图 2 纸带。比背景深一级，只靠明度区分，不加边框。 |
| `--ink` | `#1c1b18` | 正文与主线条。暖黑，和纸色同一色相，不用 #000。 |
| `--ink-2` | `#48443c` | 导语、图注、边注等次级文字。 |
| `--ink-3` | `#777164` | 元信息、标签、坐标轴。仍满足大号/标签级可读对比。 |
| `--rule` | `#d5ccb9` | 细分隔线、基线虚线。 |
| `--sea` | `#1d5266` | 唯一主强调色：kicker、首字、链接 hover、合成潮位曲线、注释编号、进度条。深海蓝，题材本身的颜色。 |
| `--sea-wash` | `#1d526614` | 移动端展开的边注底色、注释编号的点按底。 |
| `--brass` | `#94661c` | 次强调，只出现三处：图 2 的钢丝、引语下的短线、文末"月相"结束符。对应机器的黄铜。 |
| `--select` | `#cfe0e3` | 文本选中色。 |

深色（`prefers-color-scheme: dark`）：paper `#161513`、paper-2 `#201e1b`、ink `#e9e3d6`、ink-2 `#bdb5a5`、ink-3 `#8c8577`、rule `#3a362f`、sea `#86bfd1`、brass `#d4a65a`、select `#2c4a54`。深色不是简单反相：强调色提亮降饱和，背景保持暖调，避免深色下蓝色发"荧光"。

所有 SVG 内的颜色都通过 class 引用这些变量，所以两张图在深色模式下同步切换。

## 构图与间距

用一个带命名线的 CSS Grid 统一整页：`full / wide / text / margin`。

- **≥1120px**：`[full] 1fr | [wide] 5rem | [text] 36rem | 3rem | [margin] 14rem | 1fr`。正文栏 36rem（19px 字号下约 66 字符），右侧 14rem 页边栏放边注。整组宽 58rem，正文整体偏左，右侧留给注释——这是"有边注的书页"的结构，而不是居中单栏博客。
- **720–1119px**：去掉页边栏，正文两侧各留 3rem 的"wide"轨道给图片外扩。边注变成可点开的内联注。
- **<720px**：两侧 1.25rem（20px）边距，所有内容回到同一栏，375px 下正文宽 335px。

对齐：标题、kicker、导语、署名、正文、尾注全部左对齐在同一条 `text-start` 线上；图片和引语在宽屏向左外扩到 `wide-start`，图注再缩回 5rem 与正文对齐——图可以"出格"，文字不出格。

垂直节奏：小节标题上 3.25rem、下 1rem（贴近它所引导的段落）；图与边栏上下约 2.5–2.75rem；文末到尾注 3.5rem，尾注到"本期还有"4.5rem，层级越高间距越大。标题区上边距 `clamp(2.75rem, 7vw, 5.5rem)`，给标题呼吸。

## 几何、深度与质感

- **几乎没有圆角**：边栏 2px（只为不让色块边缘发硬），注释编号点按区 3px，`.key` 圆形编号是唯一的正圆。
- **没有阴影**。深度只靠两件事：明度层级（paper / paper-2）和线。纸面上不该有浮起的卡片。
- **线的语法**：1px 墨色粗线 = 结构起点（刊头底、图框顶、尾注顶、页脚顶）；1px rule 色细线 = 次级分隔（图框底、表格行）；2px 虚线 = 图内基线。图框只有上下线、没有左右线，像期刊里的图版。
- **质感**：不加噪点、不加纸纹理。"纸感"全部来自色温和衬线本身。唯一的"装饰"是那条真实潮位线，它也是数据。
- 文末结束符是一个用 `box-shadow: inset` 切出的黄铜色残月，而不是传统的 ■。

## 动效与交互状态

- **阅读进度条**：顶部 2px 深海蓝，`transform: scaleX()`，`requestAnimationFrame` 节流，只按文章本身的高度计算（不含"本期还有"和页脚）。
- **链接**：默认是 45% 透明度的深海蓝下划线，`text-underline-offset: 0.18em`；hover 时文字和下划线都变成实色深海蓝，160ms 过渡。
- **"本期还有"卡片**：整块可点，hover 只改变标题颜色，不位移、不加阴影。
- **边注**：桌面端常驻页边栏；<1120px 时编号带浅底色，点按（CSS checkbox，无 JS）后在段内展开为左侧细蓝线 + 浅蓝底的注释块，再点收起；编号在展开态底色加深。
- **焦点**：全局 `:focus-visible` 2px 深海蓝描边 + 3px offset；边注的隐藏 checkbox 可键盘聚焦，焦点环通过 `:has()` 画在可见的编号上。
- `prefers-reduced-motion` 时取消所有过渡。另有 `@media print`：隐藏进度条、导航和推荐，边注改为正文内展开，图与边栏避免跨页断开。

## 我在意的细节

1. **图 1 的曲线是真算出来的**：M₂ 12.42h、S₂ 12.00h、K₁ 23.93h 三个真实周期，用 Python 采样生成路径。所以合成曲线真的会从大潮衰减到小潮，日不等现象也真实可见——图注说的事情图里确实发生了。
2. **图 2 的钢丝几何是精确的**：上下两排滑轮水平间距正好等于直径（44 = 2×22），所以钢丝在滑轮之间是严格竖直的切线，用 SVG 弧线绕过下排滑轮底部、上排滑轮顶部，没有"差不多"的折角。笔尖起点与纸带上曲线的起点对齐。
3. **SVG 文字在三个断点下有三套字号**（10 / 12 / 22 个用户单位），抵消 viewBox 缩放，保证 375px 下图内标注仍约 10px，而桌面不会大到 15px。
4. **图 2 用编号圆点 + 图注图例**，而不是在图里写长句标注——长标注在手机上必然挤爆，编号在任何宽度下都成立，并且图注里的 `.key` 与图内圆点样式一致。
5. **首字下沉**优先用 `initial-letter: 3` 精确对齐三行，不支持时退回手调的 float（4.15em / 0.82 行高）；首字母 T 放在 lead-in span 之外，避免 `::first-letter` 继承 0.8em 的字号陷阱。
6. **引语的开引号悬挂**（`text-indent: -0.42em`），让引语文字的左缘与上方栏线对齐；正文段落也开了 `hanging-punctuation: first`。
7. **数字两套**：正文用旧式数字（1872、1953 融入小写字母的高度），表格与标签用等宽对齐数字。
8. **排印字符**：弯引号、撇号、细空格包围的 em dash（`&thinsp;—&thinsp;`）、数字与单位之间的不换行空格（`12.42&nbsp;h`），段末常用 `&nbsp;` 防止孤字。
9. **标题 `max-width: 13ch` + `text-wrap: balance`**，避免在宽屏上拉成一行长标题；导语与段落用 `text-wrap: pretty`。
10. **手机端开启 `hyphens: auto`**，桌面端关闭——窄栏需要断字来避免大空洞，宽栏不需要。
11. **边注的计数器**由 CSS counter 驱动，正文编号和页边注释编号永远一致，增删注释不会错号。
12. **边栏里的潮汐表**给高潮行的标签上色，表头用墨色粗线、行间用细线——一个最小化的"真实表格"，并附上真实可用的"十二分之一法则"。
13. **深色模式下的残月结束符**用 inset 阴影切出，阴影颜色取背景变量，因此在两种模式下都是正确的月相。

## 我刻意回避的做法

- 居中单栏 + 巨大 hero 图 + 渐变遮罩上压白字的"Medium 式"头图。
- 卡片、阴影、圆角大于 4px 的任何容器。
- 引语左侧粗竖条（blockquote 的默认套路），改用悬挂引号 + 下方一小段黄铜线。
- 第二种强调色泛滥：黄铜只出现三次。
- Inter / 系统无衬线做正文或标签；紫蓝渐变；emoji 图标；"分享到"按钮条；作者圆形头像。
- 为了"有图"而画的装饰性 SVG 插画——两张图都承载论证。
- 浮动的目录侧栏和吸顶导航：这是一篇 9 分钟的文章，不需要导航负担。
- 动画入场（滚动淡入）。长文阅读时内容不应该自己动。

## 这是"我"的习惯

在大多数设计里都会做的：
- 用 CSS 变量定义一套很小的调色板（纸 / 两级纸、三级墨、一条规线色、一个强调色），并为深色模式单独调过而不是反相。
- 暖色中性色而非纯黑纯白。
- 一个强调色原则，克制使用。
- 用线和明度建立层级，而不是阴影和卡片。
- 等宽字体做小号元信息标签（大写 + 字距）。
- 用命名网格线（`full / wide / text`）控制"出格"元素。
- 关注排印字符、数字样式、`text-wrap: balance / pretty`、`:focus-visible`、`prefers-reduced-motion`。
- 图表用真实数据或真实公式生成，而不是手画"看起来像"的曲线。

只为这个题目做的：
- 边注（sidenote）体系和偏左的书页结构——这是长文/学术题材特有的。
- 首字下沉、lead-in 小型大写、首行缩进代替段间距——纸质杂志的惯例。
- 深海蓝 + 黄铜的配色，以及标题下的潮位线、残月结束符——都取自题材本身。
- Newsreader 这一具体字体选择（因为它的光学尺寸轴正适合一种字体承担全部层级）。

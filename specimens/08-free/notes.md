# 一盏 · 功夫茶计时：设计笔记

## 模型

Opus 5.5，模型 ID：`claude-opus-5-5`

## 为什么选这个主题

我想找一件“计时”本身就有温度的事。厨房计时、番茄钟都只是数字在倒数；功夫茶不一样，每一泡的秒数不同，时间一到茶汤的颜色和滋味就会变。计时器在这里不是闹钟，是在帮你看着一盏茶。

这个主题能同时满足题目的三项要求：
- **有内容**：六款茶的真实冲泡参数（水温、投茶量、茶水比、每泡秒数）和我写的品鉴短句；
- **有功能**：可以启动、暂停、按 ±5 秒微调、跳到任意一泡、换茶；
- **有状态**：待注水、浸泡中、已暂停、出汤、整席结束，外加本席记录、滋味标签、茶记，全部存在本地。

它也让我能用一个具体的视觉隐喻代替装饰：盖碗俯视图里茶汤颜色随浸泡逐渐变深，后几泡的汤色逐渐变淡——这在现实中也成立。

## 设计立场

方向：**安静、纸感、有一点手作气的工具**。像一张放在茶盘边的卡片，而不是一个 App。浅色为主，暖白纸底，墨色文字，只有一个强调色：茶汤的琥珀色。

为什么：泡茶是慢的、手上的事，界面应该退后，只在关键时刻（出汤）说话。所以平时整个界面几乎是单色的，琥珀色只出现在进度弧、当前一泡的标记和“出汤”状态上——它一出现就意味着“该倒了”。

考虑过又放弃的方向：
- **深色、高对比、仪表盘式**：数字很醒目，但像健身计时，和茶的气质相反。保留了暗色模式，但它是浅色设计的转译，不是主设定。
- **浓烈东方元素**（水墨、印章、竖排、祥云纹）：容易变成符号堆砌。我只保留了宋体标题、字间距和少量中文数字，让“中式”留在节奏里而不是图案上。
- **大面积卡片 + 渐变的 SaaS 版式**：太常见，也和“一张纸”冲突。三栏全部在同一张纸面上，只用细线分区。
- **全屏只有一个大圆环的极简计时**：好看但内容太薄，不满足“真实可用”。所以加了茶单、参数、记录三个侧栏。

## 字体

- **Noto Serif SC（思源宋体）400 / 600**：标题、茶名、茶记输入框。宋体在中文里最有“纸上”的感觉，600 的字重足够做标题又不显粗笨。回退：Source Han Serif SC → Songti SC → STSong → SimSun → serif。
- **Newsreader（opsz 6–72，400 / 500 / italic）**：所有数字（倒计时、秒数、温度、克数、时间戳）和英文副标“a gongfu tea timer”。它是带光学尺寸的文本衬线体，76px 的大数字自动切到更紧凑精致的展示字形，小号时又足够结实；数字统一用 `tabular-nums lining-nums`，倒计时跳动时不会左右晃。回退：Iowan Old Style → Palatino Linotype → Palatino → Georgia。
- **系统无衬线**（PingFang SC / Microsoft YaHei UI / Noto Sans SC）：正文、标签、说明、按钮。小字号的功能性文字用无衬线更清楚，也不额外加载字体。

字号阶梯（px）：11（kbd）· 12（标签、辅助）· 13（状态、记录时间）· 14（参数值、记录正文）· 15（正文、按钮、描述）· 16（茶单茶名）· 22（参数大数字）· 34（茶名标题，移动端 28）· 76（倒计时，移动端 64）。

行高：正文 1.7；中文描述与茶记 1.85（中文需要比英文更松）；标题 1.25；倒计时 1。

字距：分区标签 `.14em`，且在字间手动加空格（“茶 单”），模拟传统排版的疏朗；品牌字“一盏” `.12em`；茶名标题 `.06em`；按钮文字 `.12em`（短的中文按钮需要撑开）；状态行 `.08em`；倒计时 `-.01em`（大号数字稍收紧）。

## 色彩

浅色：
- `--paper #f3efe6`：页面底色，偏暖的生宣纸色，不是纯白。
- `--card #faf7f1`：选中茶项、盖碗外沿。比纸更亮一点，表示“被拿起来”。
- `--sunk #ebe5d8`：预留的下沉面。
- `--ink #23201b`：主文字和主按钮。带一点褐的墨色，比纯黑柔和。
- `--ink-2 #5c5549`：次级文字（描述、参数）。
- `--ink-3 #8e8574`：辅助文字（标签、时间戳、提示）。
- `--rule #dcd3c2` / `--rule-2 #c9bea9`：两级细线。前者分区，后者用于按钮描边和刻度。
- `--accent #9a5b1e`：茶汤琥珀色。唯一的强调色，只用于进度弧、当前步标记、出汤状态、焦点框、已选标签。
- `--accent-soft #9a5b1e14`：8% 的琥珀，用于悬停底色和新记录的闪现。

暗色（`prefers-color-scheme: dark`）：纸 `#171512`、卡 `#1e1b17`、墨 `#ece5d8`、次墨 `#b2a894`、辅墨 `#7c7363`、线 `#312c25 / #463f35`、强调 `#d49a57`（提亮以保持对比）、强调前景 `#1a140c`。依然是暖色调，不是蓝黑。

茶汤色（数据色，不是界面色）：银针 `#e3cf8f`、龙井 `#c9cc8a`、冻顶 `#d5a249`、单丛 `#c68637`、肉桂 `#9a5523`、熟普 `#5b2a16`。每一泡的汤色由基色向 `#f2e8cf`（淡汤色）插值，从第 3 泡起每泡淡 7.5%，上限 62%；洗茶水固定淡 55%。所以记录里的色点自己就能讲出“这泡茶越来越淡了”。

## 构图与间距

- 最大宽度 1232px，左右 40px 页边；三栏 `236px | 1fr | 288px`，栏间距 56px。中间栏是舞台，内容居中；两侧栏左对齐，是工具。
- 间距基本在 4 的倍数上：6 / 8 / 12 / 14 / 20 / 26 / 36 / 40 / 56。大块之间（栏与栏、区段之间）用 36–56，组内用 6–14，避免“所有东西等距”的扁平感。
- 中心栏纵向节奏：产地（小）→ 茶名（大）→ 描述（中）→ 盖碗 300px → 倒计时 76px → 状态 → 控件 → 泡次轨道。视觉重心在盖碗与数字之间，正好落在首屏中部。
- 茶单的选中态用负外边距（-14px）让底色超出文字边界，文字本身仍和标题左对齐——对齐线不因状态而移动。
- 参数区用 2×2 定义列表，中间一条竖线，像一张小票据。
- 响应式：≤1080px 右栏落到底部并成两列；≤760px 单栏，茶单变成横向滑动的胶囊，键盘提示隐藏，页边 16px。

## 几何、深度与质感

- 圆角：按钮 10px，茶项 10px，泡次 8px，kbd 4px，标签全圆。没有大于 10 的方圆角，界面保持“纸片”而不是“气泡”。
- 边框：几乎全部用 1px 细线或 `inset box-shadow` 描边（不占布局尺寸）；主按钮无描边。
- 阴影：只有两处。选中的茶项是“纸片被轻轻抬起”：`0 0 0 1px 线色 + 0 1px 2px + 0 6px 16px -10px`，阴影带褐色调（`#2a1d0d`）而不是灰黑。主按钮有一条 1px 内高光和一层低而收的投影。
- 盖碗：外沿 r124 填卡片色，内沿 r112 细线，茶汤 r106。茶汤上叠一层径向渐变（中心微亮、边缘微暗）表现液体深度，左上角一个高斯模糊的椭圆作釉面反光。60 道刻度环在最外，每 15 道一根长刻度。
- 纹理：全页叠一层 SVG `feTurbulence` 噪点，浅色 4.5% multiply、暗色反相后 6% screen，让纸底不那么“数字”。
- 记录里的色点加了内阴影（右下暗），看上去像一小盏茶而不是平面圆点。
- 茶记输入框没有框，用重复线性渐变画出信纸横线，随滚动走（`background-attachment: local`）。

## 动效与交互状态

- 倒计时用 `requestAnimationFrame` + 绝对结束时间（`endAt`）计算，标签页切走再回来也不会漂移。
- 浸泡过程中：进度弧顺时针生长，刻度逐根变墨色，茶汤从 8% 不透明度按 ease-out 曲线逐渐变浓——注水那一刻颜色出来得最快，后面越来越慢，和真实茶汤一样。
- 出汤：柔和的三音钟声（E5、B5 与一点 E6 泛音，2.4 秒衰减），主按钮变成琥珀色“下一泡”，状态行写“出汤 · 趁热分杯”；洗茶则写“倒掉洗茶水 · 叶子醒了”，且不进入记录。
- 新记录出现时背景从 8% 琥珀淡出（1.2 秒）。
- 主按钮五种文案：开始浸泡 / 暂停 / 继续 / 下一泡（或“收席”） / 再来一席。
- ±5 秒：待注水时改本泡设定秒数；浸泡中直接推移结束时间；剩余 ≤1.5 秒时“−5”禁用，避免一按就结束。改过的泡次在秒数后加一个琥珀色小点，并按茶记住。
- 悬停：茶项和泡次出 8% 琥珀底；次要按钮描边加深并浮出卡片色。按下：按钮下移 1px。焦点：1.5px 琥珀色外框、3px 偏移。
- 浏览器标签标题在浸泡中显示剩余时间“0:12 · 一盏”，出汤时显示“出汤 · 一盏”，切走也知道该倒了。
- `prefers-reduced-motion` 时关闭所有过渡与动画。

## 我在意的细节

1. 倒计时的冒号单独着色（辅墨）并上移 0.06em，让它对齐数字的视觉中线，而不是落在基线上。
2. 所有数字等宽、衬线、lining，计时时数字宽度不抖。
3. 茶汤颜色随泡次递减，且记录里每一泡的色点保留当时的颜色——记录本身就是一条渐变。
4. 茶汤变浓的曲线是 ease-out，模拟真实浸出速度。
5. 分区标签字间加空格（“本 席”“茶 记”），用排版而不是图标做分区。
6. “第三泡”用中文数字，秒数用阿拉伯数字——叙述用中文，测量用数字。
7. 洗茶是一步但不算一泡、不进记录，泡次编号也从洗茶之后开始数。
8. 选中茶项时文字对齐线不动，只有底色向外扩出。
9. 主按钮在“出汤”状态才换成琥珀色——全页唯一一个彩色实心块，只在需要你动手时出现。
10. 茶记自动保存，只在停笔 0.5 秒后淡出一句“已记下”，不打扰书写。
11. 声音按钮的声波线在静音时淡出，而不是换一个划掉的图标。
12. 空格键开始/暂停、`[` `]` 调整、`N` 下一泡；在输入框里打字时快捷键自动失效；按住空格不会连发。
13. 茶单底部一句“茶是你的，不是表格的”——参数是起点，不是规定。
14. 换茶时每款茶的微调分别记住，下次再泡同一款会延续你的口味。

## 我刻意回避的做法

- 紫蓝渐变、玻璃拟态、发光描边、彩色大阴影。
- 每个区块一张白卡片加 16px 圆角 + 阴影的“卡片墙”。
- emoji 和图标库堆出来的功能感；全页只有两个自绘图标（品牌盏、声音）。
- 用左侧彩色竖条表示选中。
- 把中国风做成纹样（祥云、水墨、印章红）。
- 弹窗确认、toast 通知。换茶、跳泡、清空都是直接生效的，因为代价都很小。
- 拿纯黑 / 纯白做文字和底色。
- 为了“丰富”而加图表——这里唯一的数据可视化就是那一碗茶汤的颜色。

## 我眼中的"美"

我认为界面的美来自**克制带来的清晰**，以及**和真实事物之间的一致**。克制是说：颜色、字号、阴影的每一种用法都对应一个意思，不多出一种；于是当某个东西变化时（主按钮变琥珀色），人一眼就懂。一致是说：视觉不是贴上去的，它来自被表达的东西本身——茶汤真的会随浸泡变深、随泡次变淡，所以界面里的颜色也这样变。

还有一层是**节奏**：大与小、密与疏、静与动之间的落差。一个 76px 的数字旁边放 12px 的标签，大片留白里放一条细线，这些落差让眼睛有路可走。

最能代表这一点的几处：
- 盖碗里逐渐变浓的茶汤，和记录里逐泡变淡的色点；
- 全页几乎无色、只在“出汤”一刻亮起的琥珀主按钮；
- 倒计时的衬线等宽数字和那颗被扶正的冒号；
- 茶单、参数、记录三处都只靠细线和字距分区，没有一张卡片。

## 这是"我"的习惯

- 暖中性底色 + 一个强调色，强调色只在“有意义的时刻”出现。
- 带色相的灰（这里偏褐），不用纯灰、纯黑、纯白。
- 衬线体做标题与数字，系统无衬线做功能文字；数字一定 `tabular-nums`。
- 细线（1px、inset shadow）分区，阴影极少且带底色色相。
- 用负外边距让状态底色外扩而不移动对齐线。
- 小标签加大字距、降一级颜色，代替图标。
- 动效只表达状态变化，时长 150–600ms，ease-out，并尊重 reduced-motion。
- 写真实、略带个人语气的文案，而不是 Lorem ipsum 或营销腔。
- 暗色模式是同一套色彩逻辑的转译，不是反相。

## 如果再给我一倍时间

- 叶底与茶汤的细节：浸泡中盖碗里加几片缓慢舒展的叶片（SVG 路径变形），出汤后茶汤“倒走”的过渡。
- 茶单可编辑：添加自己的茶、改每泡秒数、按壶容积自动换算投茶量。
- 记录页：跨多席的历史，按茶看你每一泡实际用的秒数和标签分布，找出自己的口味曲线。
- 更认真的声音设计：采样一只真实的铜磬，或按茶类给不同音高。
- 竖排模式：茶记与描述支持竖排阅读，作为一个可切换的“书页”视图。
- 在真实设备上校对：Windows 下 Microsoft YaHei 与 Noto Serif SC 并排时的灰度平衡、iOS 安全区、低端安卓上噪点纹理的性能。
- 无障碍再走一遍：倒计时剩余 10 秒、5 秒时的屏幕阅读器播报节奏。

# Verbatim 落地页 · 设计笔记

## 模型

Opus 5.5，模型 ID：`claude-opus-5-5`

## 设计立场

产品叫 **Verbatim**（逐字）。它的核心承诺不是"AI 帮你总结"，而是"每条结论都能回溯到客户说那句话的那一秒"。所以我把方向定为 **"研究者的笔记本 + 编辑出版物"**：暖白纸色底、墨黑正文、一支荧光笔黄做唯一的强调色。荧光笔是研究者在转录稿上真正会做的动作，它同时是品牌符号（logo 底部那一道黄）、交互隐喻（Hero 里引文被"划出来"的动画）和视觉锚点。

页面叙事顺序：承诺（Hero + 真实感产品界面）→ 痛点（"洞察在第 14 通电话里，没人找到"）→ 三步流程 → 可交互的搜索演示（"拿到收据"）→ 证据链（深色块，全页唯一反相区域）→ 集成 → 客户证言 → 安全 → 定价 → FAQ → 收尾 CTA。证据链被放在中段并用反相处理，因为它是这个产品和"又一个 AI 摘要工具"的分水岭。

考虑过又放弃的方向：
- **深色科技风 + 渐变光晕**：B2B AI 产品的默认长相，和"可信、可核查"的气质相反，也会让页面与无数竞品无法区分。
- **纯瑞士网格、无衬线到底**：干净但冷，丢掉了"人说的话"这层温度。引文需要一个有声音的字体。
- **插画驱动（人物、对话气泡）**：可爱，但会削弱专业度，而且对话气泡是这个品类最陈旧的图像。我用真实感的产品片段代替插画——让产品本身当插图。

## 字体

- **Newsreader**（衬线，可变光学尺寸 6–72）：标题、所有客户引文、大数字、证言。选它是因为它本就是为屏幕阅读设计的报刊字体，大字号时光学尺寸会自动收紧，斜体有真正的"说话感"——引文用斜体，让"客户的声音"在视觉上始终与"我们的叙述"区分开。回退：Iowan Old Style → Palatino → Georgia。
- **Inter**：正文、UI、按钮、标签。在产品模拟界面里它必须像真实软件，Inter 是最诚实的选择。开启 `ss01`、`cv11` 让字形更开阔。回退：系统 UI 栈。
- **JetBrains Mono**：时间戳、眉标（eyebrow）、计数、元数据。时间戳是这个产品的"货币"，用等宽字让它们对齐、像可点击的坐标。回退：ui-monospace → Consolas。

字号阶梯（px）：11 / 12 / 13.5 / 15 / 15.5 / 17（正文）/ 19（lede）/ 24（问题区导语）/ 26（步骤标题）/ 32–48（H2，clamp）/ 44–88（H1，clamp）。移动端正文降为 16。

行高：H1 1.0；H2 1.08；CTA 大标题 1.02；引文 1.45–1.5；正文 1.6；lede 1.55；FAQ 答案 1.65。

字距：H1 −0.028em；H2 −0.018em；大数字 −0.03em；正文 0；眉标与等宽大写 +0.06~0.08em。大字收紧、小号大写放开，这是保持各字号"灰度"一致的基本操作。数字统一 `lining-nums tabular-nums`。

## 色彩

| 变量 | 值 | 角色 / 理由 |
|---|---|---|
| `--paper` | `#F6F3EC` | 页面底色。暖白，像研究笔记本，比纯白降低刺眼感，并让白色卡片能"浮"起来 |
| `--paper-2` | `#EFEADF` | 次级底色（模拟界面的笔记侧栏） |
| `--card` | `#FFFDF8` | 卡片、界面面板。不是纯白，跟纸色同一色温 |
| `--ink` | `#1B1A17` | 正文、主按钮、反相区底色。略暖的近黑，避免纯黑的生硬 |
| `--ink-2` | `#4A473F` | 次级正文 |
| `--ink-3` | `#7A7568` | 元数据、注释（在纸色上对比度约 4.5:1） |
| `--rule` / `--rule-soft` | `#DCD5C6` / `#E7E1D4` | 两级分隔线。全页主要靠线而不是阴影来组织结构 |
| `--mark` | `#F3DE6B` | 荧光笔黄。唯一的品牌强调色，只用于"被划出来的重要内容"：高亮引文、标签徽章、证据链当前节点 |
| `--accent` | `#2F5D50` | 深松绿。功能色：链接悬停、勾号、焦点环、受访者名字、引用角标。黄色不能承担文字对比度，所以需要一个暗色伙伴 |
| 标签四色 | 蓝 `#DCE6EE/#2D4A63`、玫瑰 `#F1DEDA/#7A3A2E`、鼠尾草 `#DFE7DA/#3C5A33`、沙 `#EDE3CC/#6B5424` | 仅出现在产品模拟界面里的主题标签。低饱和、同明度，确保像"真软件"但不抢戏 |

主按钮用墨黑而不是品牌色，是刻意的：页面上最"响"的颜色是荧光黄，它属于内容（客户的话），而不是属于"买我"。

## 构图与间距

- 容器最大宽 1200px，侧边距 `clamp(20px, 4vw, 40px)`，375px 时为 20px。
- 不用固定 12 栏，而是用比例分栏：标题区多为 5:6 或 4:7（左窄右宽），让标题与说明形成"一高一低"的错落，而非居中对称。只有证言和最终 CTA 居中，作为节奏上的"停顿"。
- Hero 标题左对齐、宽度限制在 ~820px，产品界面横跨全宽放在下方——先读承诺，再看证据。
- 区块间距 `clamp(88px, 11vw, 144px)`，充裕但不空洞；区块内标题到内容 56px；卡片内边距 28px（移动 22px）。基础节奏是 4 的倍数，常用 8/12/14/18/24/28/40/56/64。
- 正文行宽约束在 30–36em。
- 断点：1040（导航折叠、双栏变单栏）、860（产品界面、步骤、定价变单列）、640（手机细节：隐藏非必要元素、统计改为纵向列表）。

## 几何、深度与质感

- 圆角三级：4px（标签、徽章）/ 8px（按钮、内卡）/ 12px（大面板）。胶囊形只给"筛选 chip"和切换器，因为它们是可选状态而不是动作。
- 边框优先于阴影：几乎所有结构由 1px 暖灰线承担。阴影只给两个"浮在纸上的软件窗口"（Hero 界面、搜索演示）和推荐定价卡：`0 1px 0 rgba(...,.04), 0 12px 32px -12px rgba(...,.18)`——一道贴底细线加一团负扩散的柔影，像纸上放了一块屏。
- 统计数据和安全条目用一根墨黑的顶线（1px solid ink）起头，模仿报刊的栏目线。
- 荧光笔效果用 `linear-gradient` 背景 + `background-size` 只覆盖下方 62%，像真的笔划没完全盖住字母上缘；`box-decoration-break: clone` 让跨行高亮每行都完整。
- 没有噪点纹理、没有玻璃拟态（导航的轻度模糊除外，仅为滚动时可读）。

## 动效与交互状态

- **Hero 高亮扫过**：页面加载约 0.5s 后，引文的黄色底从左向右"划"出（1.1s，`cubic-bezier(.2,.7,.2,1)`）。这是全页唯一一个"表演性"动画，并且有意义——它演示了产品做的事。
- **滚动显现**：区块 14px 上移 + 淡入，0.7s，只触发一次。无 JS 时直接显示。
- **搜索演示**：三个示例问题 chip，点击后结果区淡出 → 换内容 → 淡入（200ms），`aria-pressed` 表达状态，`aria-live` 播报。输入框有闪烁光标，暗示"可以问"。
- **定价切换**：年付/月付，价格与说明文字同步变化。
- 按钮：悬停加深、箭头右移 3px、按下下沉 1px；ghost 按钮悬停边框加深并填卡片色。
- FAQ：原生 `details`，加号的竖线旋转 90° 收成减号。
- 导航：滚动超过 8px 才出现底线。
- 所有可聚焦元素有 2px 松绿焦点环，offset 3px。
- `prefers-reduced-motion` 下关闭所有动画与过渡，高亮直接呈完成态。

## 我在意的细节

1. 引文全部用 Newsreader 斜体 + 弯引号（“ ”），叙述全部用正体——读者不用想就知道哪句是客户说的。
2. 搜索演示的总结句带上标角标（¹²³），与下方每条引文的角标一一对应，把"会给出处"这件事做成可见的结构，而不只是一句卖点。
3. 时间戳统一等宽字体，并带 ▸ 播放符号，暗示可点击跳转。
4. 波形图用确定性伪随机生成，进度位置（45%）与播放时间 18:42/41:10 精确吻合。
5. 产品界面里的数据彼此自洽：Hero 的 Priya 引文、步骤二的 "Interview 07 · 18:16"、证据链里的同一句话和 "6 interviews"、Linear 卡片 LIN-2214 —— 整页讲的是同一个研究项目。
6. 统计数据下方写了出处与时间窗口的脚注；定价区解释了"什么算研究者席位"。可信感来自具体。
7. 大数字的单位（min、%、×）缩小为一半并降为次级灰，数字本身才是主角。
8. 标题用 `text-wrap: balance`、段落用 `text-wrap: pretty`，并在 "ready to&nbsp;quote"、"already&nbsp;use" 处用不换行空格防止孤字。
9. 荧光笔高亮使用 `box-decoration-break: clone`，换行时每段都有完整笔划。
10. 移动端：Hero 两个按钮等分撑满；统计从三栏横排变成带分隔线的纵向列表；⌘K 提示和窗口三个圆点在手机上隐藏（手机上没有意义）；所有网格用 `minmax(0,1fr)` 防止长内容撑破 375px。
11. 定价卡用 `margin-top:auto` 把按钮对齐到卡片底部，三张卡的按钮在一条水平线上。
12. 客户 logo 用六种不同的字体处理模拟真实的字标多样性，而不是一排同字体的名字。

## 我刻意回避的做法

- 紫蓝渐变、光晕球、玻璃卡片、"✨ AI-powered" 徽章。
- 居中堆叠的 Hero + 一张浮着的笔记本电脑截图。
- 三列图标 + 标题 + 一句话的"功能网格"（每个都用 emoji 或线性图标）。我用三张带微型界面的步骤卡代替。
- 头像墙 + 五星评分的证言轮播。只放一条有观点的证言，配三个具体数字。
- "Revolutionize / Unlock / Supercharge" 这类空洞动词。文案尽量写具体场景（"finance 转发来的超额账单"）。
- 用阴影堆层次；用多种强调色。
- 无意义的视差和逐字打字动画。

## 这是"我"的习惯

大多数设计里都会做的（个人风格）：
- 暖色中性色而非纯白纯黑；一个强调色，再配一个承担可读性的暗色功能色。
- 衬线标题 + 无衬线 UI + 等宽元数据的三字体系统，眉标用等宽大写加短横线。
- 用 1px 线组织结构，阴影极省。
- 大字负字距、比例分栏的左对齐构图，只在节奏停顿处居中。
- 用 HTML/CSS 搭出的"真实感产品片段"代替截图和插画。
- 具体、自洽、带出处的假数据；reduced-motion、焦点环、`minmax(0,1fr)` 之类的基础功。

只为这个题目做的：
- 荧光笔黄作为品牌色和贯穿全页的隐喻（高亮扫过动画、logo、徽章、证据链节点）。
- 引文斜体 / 叙述正体的严格区分。
- 搜索结果的角标引用系统、证据链的反相区块。
- 时间戳作为视觉"货币"处处出现。
- "Readers are free" 的定价叙事——这是为研究工具"需要全公司都看"的特性写的。

## 如果再给我一倍时间

- 在真实浏览器里逐断点截图复查（这次按规则没有使用预览工具），尤其是 375px 下产品界面和搜索卡的文字换行。
- 做暗色模式：纸色 → 暖炭灰，荧光黄降饱和以免在深底上刺眼。
- 让 Hero 界面可交互：点击时间戳，波形进度跳转并高亮对应行。
- 证据链做成可逐层展开的交互（点 Finding 展开 Notes，再展开 Quote）。
- 为 Newsreader 做子集化与 `size-adjust` 回退字体度量匹配，消除字体加载时的布局跳动。
- 加一个"导入你的一条录音，60 秒看到结果"的真实转化路径设计，以及客户案例页的入口。
- 更认真地设计 logo：现在的双引号 + 黄色划线是可用的，但还不够独特。

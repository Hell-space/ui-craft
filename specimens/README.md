# Opus 5.5 原作样本

这里是 Claude Opus 5.5（`claude-opus-5-5`）在**不带任何风格提示、不使用任何 skill** 的条件下做的八个界面，以及它的审美自述和对本 skill 旧版的评审。它们是 `references/opus-taste.md` 的原始依据。 样本里出现的墨绿保留作原始记录，新作按[当前配色要求](../references/color.md#检查大面积偏色)选色。

[游戏美术取样记录](09-interview/game-art.md)保存单独在 Claude 桌面端进行的访谈与反例，记录了条件化方案与一个缩略构图；[游戏美术判断](../references/opus-game-art.md)将其整理为可实施的选择。

本轮又让 Claude Code 的 Opus 5.5 · 超高从空白完成[风洞试验室](10-wind-tunnel/index.html)，并按已有 API 改造[电影拷贝检查台](11-film-inspection/index.html)。两份都有实际源码、离线入口，以及真实截图往返修稿的[验证记录](../evals/frontend-studio.md)。

[《回层》三张唱片封面](12-stairwell/index.html)由另一个 Opus 5.5「超高」会话从空白创作。三张都从同一座楼梯间底部向上看，上行、折返与关门由步迹的路径或井口的明暗区别。[夸克实图](12-stairwell/proof.png) · [两种尺寸的评稿与跨题迁移](../evals/series-study.md)

**怎么用**

- 做同类题目前，读对应目录的 `notes.md`：它记录了立场、被否掉的方向、每个颜色和字体的理由、在意的细节、刻意回避的做法。这是最值得读的部分。
- 需要看某个手法具体怎么写时，读 `index.html` 里的 `<style>`（tokens 都在 `:root`）。
- 想看效果就在浏览器里打开 `index.html`。它们引用了 Google Fonts，离线时走回退栈。
- **不要照搬题材、配色与文案。** 这些样本用来校准水准与手法；每个新题目的立场句、贯穿装置和强调色都应当从它自己的题材里来。

原八作是 Opus 凭推演写成的。后续在离线夸克用 1366×864、360×780 各走一条真实路径。桌面八例均无整页横向溢出。窄屏工单工具、账簿样机、组件页、茶计时器超出视口 808、15、87、449 像素。工单工具保留 1168 像素最小宽度，账簿的样机外框宽 390 像素。它们保留原貌，适合拆读具体手法。交付新的手机页面时，用当前内容重新编排并实测。

| 原作 | 两种宽度均实际操作过的部分 |
|---|---|
| 产品页、运营后台 | 研究演示切换到报表问题后出现新问题和回答。后台由 30 天切为 14 天，区间成交从 ¥178 万变为 ¥82.5 万 |
| 工单、记账 | 点击另一条工单后选中 ID 及网址片段一致。选择 11 月 2 日的柱条更新日读数，随后可隐藏金额 |
| 茶品牌、长文 | 导航进入山场，手机菜单收起。文章向下滚动后，阅读进度增加 |
| 组件、计时 | 方向键选中 Ware，其面板显示，原面板隐藏。茶计时可顺序开始、暂停、继续 |

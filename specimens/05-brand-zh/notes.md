# 丹崖茶号 · 首页设计笔记

## 模型

Opus 5.5，模型 ID：`claude-opus-5-5`

## 设计立场

**方向：一本印出来的茶册，而不是一个电商首页。** 武夷岩茶的核心价值是"山场"和"焙火"，这两件事都是可以被讲清楚、被数据化的（坑涧名、海拔、焙火道数、焙温、出汤秒数）。所以我把页面当作一份有编号栏目的"茶单 + 说明书"：米纸底色、宋体、细线分隔、数字用旧式衬线体，像茶号每年秋天印给老客的那张单子。

品牌叫"丹崖"——武夷山是丹霞地貌，岩茶的"岩"就是这些红色岩壁。主张句"一泡岩茶，半在山，半在火"把整页结构定下来：山场一节、焙火一节，茶单夹在中间。

没有摄影，所以唯一的大图是内联 SVG 画的丹霞岩壁：平顶、陡壁、横向岩层、雨水冲出的竖向沟痕、崖顶茶丛、岩脚梯田、九曲溪。它更像博物图鉴的示意图而不是插画，这和"说明书"的调子一致。

**考虑过又放弃的：**
- **水墨 / 留白禅意风**（大面积空白、毛笔字、一枚朱印）：太多茶品牌这么做了，而且它回避信息——用户真正想知道的是"这泡茶是哪个坑的、什么火、多少钱"。
- **全深色高级风**（黑底金字）：适合礼盒，不适合一个强调"如实标注、不推销"的小茶号。我只把深色留给"焙火"一节，作为焙间炭火的情境切换。
- **朱红印章色作主色**：中式品牌的默认答案。我改用偏褐的锈红（丹岩色），它来自岩壁而不是印泥，和题材有直接因果关系。
- **卡片式商品网格**：五款茶用卡片会显得像商城，用一张有表头的茶单更像茶号自己的口吻，也方便横向比较山场与焙火。

## 字体

| 字体 | 用途 | 理由 |
|---|---|---|
| **Noto Serif SC**（400 / 600 / 900，Google Fonts） | 标题、正文、茶名 | 开源思源宋体，900 字重足够做首屏竖排大字，400 做长段落也不累眼。宋体的横细竖粗有"刻印"感，适合茶单。 |
| 回退：`Source Han Serif SC`, `Songti SC`, `STSong`, `SimSun`, serif | 离线 | 系统里只要有任何宋体就能保持同一气质；Windows 最差退到 SimSun。 |
| **系统黑体栈**：`-apple-system, PingFang SC, Hiragino Sans GB, Microsoft YaHei UI, Microsoft YaHei, Noto Sans SC` | 导航、按钮、标签、规格、表头、表单 | 功能性的小字用黑体，和宋体正文拉开"读"与"查"两种层级。不加载网络字体，零成本。 |
| **旧式衬线数字栈**：`Iowan Old Style, Palatino Linotype, Palatino, Georgia` | 价格、亩数、克数、海拔、秒数 | 思源宋体的西文数字偏窄偏现代；Palatino 一类数字更有书卷气，和宋体搭。开启 `lining-nums tabular-nums` 让价格列对齐。 |

**字号阶梯（px）：** 12（标签）· 12.5–13（规格、注释）· 14.5–15（次级正文、风味）· 16–17（正文，移动端 16）· 19（小标题）· 21（导语、卡片标题）· 22（茶名）· 24（价格）· 32（移动端栏目标题）· 40（栏目标题、关键数字）· 44（首屏数据）· clamp(30, 4vw, 52)（立场句）· clamp(64, 8.4vw, 112)（首屏竖排标题，移动端 58）。

**行高：** 正文 1.85–1.95（中文需要比西文更松）；导语 1.75；栏目标题 1.3；竖排大标题 1.08；数字 1。

**字距：** 中文标题 0.06–0.14em（宋体大字不加字距会显得挤）；黑体标签 0.12–0.16em；品牌名 0.24em；竖排副标"武夷正岩"0.34em；数字一律 0。

## 色彩

| 变量 | 值 | 角色 / 理由 |
|---|---|---|
| `--paper` | `#F2ECE1` | 主底色。偏暖的米纸色，不用纯白，避免"网页感"。 |
| `--paper-2` | `#E9E1D2` | 茶单一节和订阅卡的底色，用一档更深的纸色做分区，不靠阴影。 |
| `--ink` | `#211D18` | 主文字。暖黑，带一点褐，和纸色同一色相。 |
| `--ink-2` | `#574F45` | 正文段落、说明文字。 |
| `--ink-3` | `#8A8072` | 标签、表头、次要信息。 |
| `--rule` / `--rule-strong` | `#D5CABA` / `#B9AC98` | 两档分隔线。结构全靠细线建立。 |
| `--rock` | `#9E4A2F` | **唯一强调色**：丹霞岩壁的锈红。用于主岩壁、焙火刻度、栏目编号、"正岩"标签、地图点位、低余量提示。 |
| `--rock-deep` | `#7A3622` | 按钮悬停、岩壁沟痕、焙火刻度中"最高一格"。 |
| `--rock-tint` | `#D9A68C` | 远处的矮崖、出汤图中前两泡（醒茶段）。 |
| `--stream` | `#6E8088` | 涧水与九曲溪。冷灰蓝，全页唯一的冷色，只出现在"水"上。 |
| 茶丛绿 | `#5E6650` | 崖顶茶丛和梯田，极小面积，灰橄榄而非鲜绿。 |
| `--kiln` / `--kiln-rule` | `#221D18` / `#463C31` | 焙火一节的深色底与分隔线。 |
| `--kiln-ink` / `--kiln-ink-2` | `#ECE3D3` / `#A89C8A` | 深色区文字，仍是暖色。 |
| `--ember` | `#D07A3E` | 炭火橙，只在焙火一节出现：时间线柱子、步骤月份。底部一圈极淡的径向光晕像焙笼里的余火。 |

原则：一个主强调色（岩），一个只属于"水"的冷色，一个只属于"火"的暖色；每种颜色都对应题材中的一个实物。

## 构图与间距

- **12 栏栅格**，最大宽度 1200px，栏间距 24px，左右页边距 `clamp(16px, 5vw, 64px)`（375 宽时正好 16–19px）。所有栅格用 `minmax(0,1fr)`，防止长中文把列撑开。
- **栏目标题行统一结构**：第 1–2 栏放编号（"01 / 本季茶单"），3–8 栏放标题，9–12 栏放一句说明。全页五个栏目重复同一骨架，像书的版式。
- **首屏三段**：竖排大标题（1–2 栏）· 岩壁图（3–8 栏）· 导语与按钮（9–12 栏），下面一条粗黑线承接四个数据。竖排标题放在最左，是中文版式里"题签"的位置。
- **立场一节**故意让两段正文从第 3 栏开始，与上方左对齐的大句子形成一级缩进。
- **茶单**是七列表格：编号 / 茶名 / 山场 / 焙火 / 风味 / 规格 / 价格；价格右对齐、等宽数字。1080 以下风味与规格折到第二行，640 以下变为"编号—茶名—价格"顶行加纵向信息的卡片式行。
- **垂直节奏**：栏目上下 120px（移动端 88px），栏目标题到内容 56px（移动端 40px），组件内部用 8 / 12 / 16 / 24 / 32 的步长。
- 山场地图在桌面端 `position: sticky`，右侧五条坑涧说明滚动时地图保持在视野内。

## 几何、深度与质感

- **圆角**：按钮、标签、表单 2px；印章 3px。几乎是直角——纸质印刷品没有圆角，2px 只是为了抗锯齿时不显得生硬。
- **边框**：全部 1px 细线，两档灰褐。栏目起始处用 1px `--ink` 实线（茶单表头、首屏数据、冲泡参数、页脚），相当于书里的"粗线开栏"。
- **阴影**：零。层级完全靠底色深浅和线来分。
- **纹理**：`body::before` 用 SVG `feTurbulence` 生成 180px 的噪点平铺，`multiply` 混合、35% 不透明度，肉眼只能感到"纸"而看不出颗粒。
- **插图**：岩壁的横向岩层是被 `clipPath` 裁进轮廓里的细线，沟痕是略弯的深色曲线；底部用渐变"雾"把岩脚融进纸色；整张图左右各 6% 用 `mask-image` 淡出，避免矩形边缘。
- **印章 logo**：2×2 方阵，右列"丹崖"、左列"茶号"，按传统印文从右往左读，竖排。
- **焙火时间线**：柱子高度示意焙温，退火期用虚线框表示"什么都不做的等待"。

## 动效与交互状态

- **入场**：带 `.rise` 的块在进入视口时从 14px 下方淡入，0.8s，`cubic-bezier(.2,.7,.2,1)`。只在 JS 运行时才加初始隐藏（`.js .rise`），无 JS 时内容完整可见。
- **出汤条**：进入视口时依次从 0 展开到对应比例，每条延迟 70ms 左右，像一泡比一泡长。宽度用 CSS 变量 `--w` 写在元素上，无 JS 时直接显示终态。
- **导航**：悬停时下方 1px 锈红线从左向右展开；页面滚动超过 8px 后顶栏出现底线（半透明纸色 + 背景模糊）。
- **按钮**：实心按钮悬停由墨黑转深岩红，幽灵按钮悬停反白为实心；箭头右移 3px；按下下沉 1px；`:focus-visible` 统一 2px 岩红描边、3px 偏移。
- **茶单行**：悬停时左侧出现一条 2px 的岩红竖线（从中间纵向展开）。
- **山场地图 ↔ 列表联动**：悬停/聚焦地图点位或右侧条目，对应点位出现外圈、文字转深红，其余条目降到 42% 不透明度。点位可 Tab 聚焦。
- **订阅表单**：本地校验，错误/成功提示用 `aria-live` 播报，成功后禁用输入。演示版不发送任何数据。
- **移动端目录**：按钮文字在"目录 / 收起"之间切换，点任一链接后自动收起。
- `prefers-reduced-motion: reduce` 下关闭平滑滚动、入场、展开动画，所有过渡时长归零。

## 我在意的细节

1. **"半岩"如实标注。** 第五款日常大红袍产自天心村周边，属于半岩产区，我给它一个灰色的"半岩"标签并写明"非正岩"——这是这个茶号可信度的来源，也是我放弃"半岩"作为品牌名的原因（行内"半岩茶"是低于正岩的等级，作品牌名会让懂茶的人误会）。
2. **印章文字顺序**按传统从右列读起，而不是网页习惯的从左到右。
3. **焙火刻度的第四格用更深的岩红**，让"中足火 / 足火"一眼和"中火"区分开，而不只是多一格。
4. **出汤图前两泡用浅色**，并在下方解释原因（醒茶、闻香），图不是装饰，是可执行的说明。
5. **价格用等宽衬线数字并右对齐**，"¥"缩小到 15px 并降一档灰，让数字本身成为视觉重心；余量少的那款用岩红提示"余 38 盒"。
6. **防止中文标点和短语被拆行**：立场句、茶室标题按语义分块包 `inline-block`，避免"半在 / 山"这种断法；首屏数据的说明文字也删短到不留孤字。
7. **竖排标题**用 `writing-mode: vertical-rl`，副标"武夷正岩"作为第二列放在左侧，符合竖排从右往左的阅读顺序。
8. **所有栅格列用 `minmax(0,1fr)`**，否则长中文会在窄屏把 12 栏撑出横向滚动——第一次渲染时就是这么坏的，修了。
9. **地图标注"位置示意，非实际比例"**，不假装是测绘图。
10. **茶室信息里写明春茶季闭门做茶的日期**、品饮费用可抵扣、每场四人——这些是真实小茶号会写、模板不会写的东西。
11. **订阅卡写"每年只发两封"并列出上一封的日期**，用具体承诺替代"订阅获取最新优惠"。
12. **电话号码用 `tel:` 链接并带国家区号**，显示时用空格分组。

## 我刻意回避的做法

- 不用大幅渐变 Hero、玻璃拟态、卡片悬浮阴影、彩色图标网格。
- 不用"匠心""臻品""东方美学"之类的空词，所有文案都落在具体的地名、数字、做法上。
- 不放假的用户评价、假的媒体 logo 墙、倒计时促销。
- 不用毛笔书法字体和水墨晕染素材——它们是"中式"的捷径，但和"说明书"的立场冲突。
- 不用表情符号或线性图标替代文字标签。
- 不用居中对称的落地页结构（大标题居中—三栏特性—CTA），全页左对齐、按栅格错落。
- 不编造 ICP 备案号和 SC 许可证号，页脚只写"见产品包装"。

## 这是"我"的习惯

**我在大多数设计里都会做的：**
- 一个强调色，其他全部是同一色相的中性色；底色不用纯白、文字不用纯黑。
- 用细线和底色深浅建立层级，几乎不用阴影；圆角很小。
- 数字单独处理：等宽、右对齐、单位缩小降灰。
- 栏目编号（01 / 02 …）和统一的栏目标题骨架。
- 小字标签用加宽字距的无衬线，正文用衬线或高可读性字体，形成"读 / 查"两种层级。
- 动效克制：只做入场淡入、悬停下划线这种程度，并且完整支持 `prefers-reduced-motion`。
- 文案追求具体：地名、日期、数量、限制条件。

**只为这个题目做的：**
- 竖排首屏标题与从右往左的印章。
- 锈红"丹岩色"、只属于水的冷灰蓝、只属于焙火一节的炭火橙和深色区。
- 丹霞岩壁的 SVG 图解、三坑两涧示意地图、焙火时间线、出汤秒数图——这些是从岩茶本身的知识结构里长出来的信息图。
- 宋体全站正文（在西文或科技类题目里我通常会用无衬线正文）。

## 如果再给我一倍时间

- 把岩壁插图做得更"地质"：用程序生成不等距的岩层、更自然的风化沟，以及随滚动缓慢移动的雾层（视差，带 reduced-motion 降级）。
- 字体子集化：只把页面用到的约 600 个汉字的思源宋体 900 打成内联 WOFF2，首屏竖排标题离线也能保持完全一致。
- 给每款茶做一个详情抽屉：完整的审评笔记、焙火记录（每道日期与温度）、冲泡曲线，以及同款往年的对比。
- 地图改成基于真实等高线数据的简化版，并让点位与茶单条目双向联动（点茶单高亮山场）。
- 做一套深色模式，焙火一节的配色可以直接扩展成全站暗色。
- 在真实设备上测试 Windows SimSun 回退时的竖排标题，必要时为无宋体环境单独调整字号和字距。
- 补充英文版或繁体版的排版规则（竖排在繁体里更自然）。

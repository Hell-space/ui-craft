## 立场、档位、预设、强调色

- **这一屏回答的问题**：下一次带它去医院是什么时候、要做什么？回答它的是首屏墨绿舞台上 76px 的"14:30"（全屏最大的东西），上面一行"11 月 13 日 周五"，旁边一个"后天"小胶囊。
- **立场句**：是一本放在手机里的宠物免疫证，而不是一个医院的服务大厅。
- **否掉的方向**：
  1. 品类最常见的样子：顶部轮播 banner + 八宫格图标（预约挂号 / 疫苗 / 美容 / 商城 / 寄养……）+ 促销卡片。打开首页的人是带着"该不该去、什么时候去"来的，不是来逛服务目录的。
  2. 卡通吉祥物 + 糖果色 + "毛孩子今天也要健康哦"问候语：占掉首屏最贵的位置，什么问题都不回答。
  3. 医疗蓝白 + 十字图标的"医院官网"语气：冷，而且把宠物主人当成病人家属；这里的高频场景是疫苗和驱虫这种例行事务。
  4. 把排班做成每位医生一张大卡片的竖向列表：三家医院六位医生要翻好几屏，比不出谁现在有空。改成一把共用时间尺。
- **档位**：3 档（叙事）。面向终端用户、低频打开（每周一两次），值得有一个尺度时刻、一块色面、一个物件和首屏编排。
- **预设**：`botanical`（植物：健康、柔和、可信、大圆角、暖影）。保留了它的字体搭配 Young Serif（数字与西文）+ Figtree（功能文字），中文全部落到系统黑体栈。
- **强调色**：`#2E5E4E` 墨绿——宠物免疫证封皮的颜色。用 `palette.py` 生成整套后，把按钮色手调到 `oklch(0.50 0.07 170)` 保证白字 5.6:1。另有一个语义色：赭石 `oklch(0.50 0.12 58)`，只给"逾期"；医院章的印泥红 `oklch(0.54 0.17 27)` 只出现在贴纸上的章里。
- **贯穿装置（物件）**：免疫证。首屏舞台就是封皮（墨绿 + 颗粒）；下面每只宠物一页内页（纸色、左侧露出 9px 封皮和装订线、表头一道粗印刷线）；每一项疫苗或驱虫是一行，过去的记录是**疫苗瓶上撕下来的贴纸**（顶部色条：墨绿 = 疫苗、麦黄 = 驱虫；印着日期；有批号条码），上面压着医院的爪印红章，各自歪 −3° 到 3°；下一次是**虚线空格**，写着到期日——已约是墨绿底，逾期是赭石底。贴纸既是物件也是数据：排在一起就是这一项的历史和节奏。点"已在家用药"会贴上一张新贴纸、盖章（bouncy 弹簧），后面再空出下个月的格子。
- **第二个物件**：要去医院的那只从封皮下面探出头，爪子搭在分隔线上（年糕是蓝猫、铜色眼；约了豆包之后换成黑拉布拉多，弹上来）。

## "做完的判据"逐条证据

0. **截图单看，好看吗？五个来源满了哪几个？**
   **没有截图，也没有目视过。** 本次任务约束不许用浏览器和预览工具，所以无法渲染。按 skill 第 9 步"确实无法渲染时选更保守的构图"，构图用的是 compositions 第 11 节的标准手机首屏（舞台在上、物件在文字下方右侧、四周留 8px 底色边），其余区块都是单列。按设计意图，五个来源：
   - 尺度：满。76px 的时间 vs 12–13px 说明，约 6 倍。
   - 色面：满。首屏整块墨绿封皮（双光源径向渐变 + 颗粒）。
   - 光与深度：满。封皮顶边高光、物件背后的光晕和投影、内页 2 档阴影、贴纸的接触影与顶边高光、弹层 5 档阴影。
   - 物件：满。免疫证内页、疫苗贴纸、医院红章、探头的猫/狗。
   - 运动：满（设计上）。首屏编排约 700ms 内到齐；排班条从左长出、空号点随后亮起；按压、弹层 smooth 弹簧、盖章 bouncy、余号数字滚动、首屏在新预约后换内容和换宠物。
   这一条的真实答案要等有人打开看。
1. **问题与主角**：见上。"14:30"是全页唯一 76px 的元素，字重和颜色也是首屏最强。
2. **立场句**：是一本放在手机里的宠物免疫证，而不是一个医院的服务大厅。
3. **只属于这个题目的三样东西**：
   - 题材色：免疫证封皮的墨绿（另有医院印泥红只在章上）。
   - 只有这个产品会写的文案："带上免疫证；打针前后 7 天别给它洗澡。"、"第 3 针后 1–2 周"、"来之前 3 天别洗澡，医生要看皮屑原样。"、"急诊号优先留给急症"、"夜班急诊不用预约，直接去北苑就行"。
   - 只有这个产品才有的物件/数据：贴着疫苗瓶标签、盖着爪印章的免疫证内页；三家医院共用一把 8–22 点时间尺的排班条（含跨夜班渐隐、10:24 现在线、空号点）。
4. **字号、灰、圆角、强调色位置**：
   - 字号 6 种：12 / 13 / 15 / 17 / 22 / 76（变量 `--fs-xs … --fs-hero`）。贴纸上的日期也是 12px。
   - 文字灰 4 级：`--text` / `--text-muted` / `--text-subtle` / `--text-faint`（faint 只给页脚同步时间这类不承载决策的信息）。
   - 圆角 3 档：4（贴纸、空格、内页装订侧、排班条）/ 14（按钮、号源卡、提示条）/ 24（舞台、内页外侧、排班卡、弹层），外加全圆胶囊与圆形头像。手机机身 60/48 是画框，不算界面。`audit.py` 报 6 种，多出的 6px、20px 来自内联的 `motion.css`（骨架屏、浮层）。
   - 强调色出现在：中间"预约"按钮、"已在家用药"实心胶囊、弹层"确认预约"、选中的号源卡与胶囊、"已约"空格、余号数字、排班条（32% 混色）与空号点、当前标签、焦点环、品牌爪印。
5. **数据自洽（验算）**：
   - 今天还能约的号：陈晓 2 + 王一舟 4 + 周南 0 + 李沐 1 + 赵启明 3 + 孙蔓（夜班不预约）= **10**，与"还能约 10 个号"一致；预约一个后变 9，对应医生的"余 n 号"和条上的空号点同步减少（JS 从同一份 `DOCS` 计算）。
   - 日期：2026-11-11 是周三；11.13 周五 = "后天"；11.21 周六；12.02 − 11.11 = 21 天；12.20 − 11.11 = 39 天；11.28 − 11.11 = 17 天；11.27 − 11.11 = 16 天；用药后下一次 12.11 − 11.11 = 30 天。
   - 免疫本汇总"1 项逾期 · 30 天内还有 4 项"：逾期 = 豆包体外驱虫（应于 11.09）；30 天内 = 年糕猫三联③ 11.13（已约）、年糕狂犬 11.27、年糕驱虫 11.28、豆包犬八联 12.02，共 4；豆包体内驱虫 12.20（39 天）和狂犬（2027.05）不计。汇总由 JS 从每行的 `data-due` / `data-state` 算出，盖章后自动变成"没有逾期 · 30 天内还有 5 项"。
   - 幼猫针间隔：09.16 → 10.14 = 28 天，10.14 → 11.13 = 30 天，符合 3–4 周一针。
   - 排班条百分比：(小时 − 8) / 14；现在线 10:24 → 17.14%。
6. **1440、1100×760、375、暗色、键盘、主要交互**：**都没有实际看过**（同上，不许用浏览器）。按代码推断：
   - 1440：左侧说明牌 + 居中的 414×868 画框，右侧留空保持画框在正中。
   - 1100×760：画框高度 `clamp(660px, 100dvh − 56px, 868px)` → 704px，内容区内部滚动，首屏能看到舞台和免疫本标题。
   - 375：≤460px 时去掉机身和灵动岛，界面铺满 `100dvh`；≤920px 时隐藏说明牌。
   - 暗色：所有角色变量用 `light-dark()`，跟随系统；说明牌上有"跟随系统 / 浅色 / 深色"切换。封皮舞台在两种模式下都是墨绿；贴纸在暗色里降到 0.89 明度，印章改为不做正片叠底。暗色文字对比已用脚本验过（最低的 subtle 在内页纸上 5.36:1）。
   - 键盘：所有按钮可 Tab；排班行是整行按钮并带完整 aria-label；弹层打开时背景 `inert`、焦点进入第一个选中项、Esc 关闭并把焦点还给打开它的按钮；"只看还有号的"收起的行 `tabIndex = -1`；排班行焦点环向内缩 3px 以免被裁。

7. **删掉的装饰、打磨的细节**：
   - 删掉 / 没加：考虑过在首屏放爪印底纹，没加（会和物件抢）；"之后"那一行末尾的"共 N 个"计数（会和猫爪撞在一起）；状态栏与标签栏的入场动画（系统 chrome 不该"进场"）；免疫本每行状态里重复的日期（日期已经印在空格里，只留"21 天后"）。

## Skill 里我觉得含糊、矛盾、难执行或不适用的地方

1. **"没有看过渲染结果的界面不算做完" vs. 本任务"不许用浏览器"**：skill 给了退路（"选更保守的构图，并在回复里明说"），但判据 0 和 6 整条都依赖渲染，无法渲染时这两条该写什么没有说。我只能写"按代码推断"。建议给"无法渲染"情形一个明确的替代检查清单（例如：按字宽估算关键行是否溢出、列出最可能出问题的 3 处）。
2. **"在页面中央放一个手机画框"时，375 宽怎么办没有指引**：specimen 笔记里是"等比缩放"，compositions 第 11 节讲的是手机首屏内部构图，没讲"展台"本身的响应式。我选了窄屏去掉机身铺满。
3. **字号下限 vs. 物件上的小字**：typography 说中文 12px 是下限、辅助尽量 13px；但贴纸、印章这类"画出来的实物"上本来就有很小的印刷字（批号、医院名）。我把印章里的字换成了爪印图形、批号换成条码，绕开了这个矛盾。skill 可以明确：物件上的装饰性小字要么 aria-hidden 并允许低于下限，要么改成图形。
4. **移动端正文字号**：product-types 说移动端正文 16–17px，typography 说中文后台 15px 是甜区、手机样本（specimen 04）大量用 13–15px。小程序首页属于哪一类不清楚。我用 15px 做列表正文、17px 做名字，没有用 16–17 的正文。
5. **"圆角全界面不超过三种"怎么数**：胶囊（999px）、圆形头像（50%）、画框机身算不算？内联的 `motion.css` 自带 6px/20px 会让 `audit.py` 报超标。建议 skill 写明"胶囊和正圆不计；画框不计"，并让 motion.css 的圆角也走变量。
6. **`audit.py` 的"纯图标按钮没有 aria-label"是误报**：它的正则 `<button…>\s*<svg.*?</svg>\s*</button>` 会从一个以 svg 开头、后面还有文字的按钮一路匹配到后面某个按钮的 `</svg></button>`。本页两个关闭按钮都有 `aria-label="关闭"`。
7. **"首屏以下的区块只淡入一次"与"每天打开好几次的工具跳过编排"之间的灰区**：预约小程序一周开一两次，我按 3 档做了编排；但没有给"低频但工具性强"的 App 一个明确判断。
8. **预设的字体对中文几乎无效**：`botanical` 的 Young Serif / Figtree 都没有中文字形，中文永远落到系统黑体，所以预设的"声音"只体现在数字和西文上。skill 可以为每套预设写一行"中文时用什么"（例如 botanical 的中文标题要不要用思源宋体）。
9. **`--text-faint` 的用途边界**：styles.css 说它"只给装饰性刻度与分隔符，不承载信息"，但同步时间、页脚这类低优先级信息用 subtle 又太重。我把页脚"上次同步 10:21"放在 faint，严格说违反了这条。
10. **"颜色作为交互信号 ≤ 5% 面积"在小程序里难以核对**：中间的实心"预约"按钮 + 实心"已在家用药" + 若干已约格子，面积估算不出来（没法渲染），也没有工具帮忙算。
11. **`motion.css` 的 `[data-reveal].is-in { filter: none }` 会吃掉元素自己的 `filter`**（比如物件的 `drop-shadow`）。motion.md 第 9 节只提醒了 transform 的冲突，没提 filter。我把投影挪到了内层 svg 上。同理，`.js [data-reveal]` 的 `transition` 会覆盖元素自身的过渡（顶栏滚动后的背景过渡因此失效），我最后去掉了顶栏的 data-reveal。这两条值得写进 motion.md。

# 游戏美术校样

此目录保存历次校样及其原始配色。旧作中的深绿色只用于前后比对。新作使用[当前配色规则](../references/color.md#检查大面积偏色)。

[潮汐修船坞](tideyard/project.godot)用实际走区对照码头的路沿、缺口与可操作摇柄，可用 F2 和 F3 比较杂物与照明。[渡口铁匠铺](forge-bench.html)是可离线打开的道具架，演示同品质物件在 32 像素下的区别、预览与装备。两件成品的取舍、输入检验和可迁移的条件见[游戏美术判断](../references/opus-game-art.md)。

# 前后对照：同一个题目，平淡版与表现力版

两版是同一道题（社区图书馆"我的借阅"页）、同一份数据、同一个立场句和贯穿装置。区别只在于有没有走 `references/visual-craft.md` 那一步。用来校准"好看"的落差，**不要照搬题材**。

| | `library-v1-flat` | `library-v2-expressive` |
|---|---|---|
| 档位 | 实际停在 1–2 档 | 3 档（叙事） |
| 尺度 | 136px 日期，其余都小 | 152px 日期 + 书架作为第二个尺度时刻 |
| 色面 | 整页米色 | 一整块印油蓝的深色舞台，带两团光与颗粒 |
| 光与深度 | 全平，只有 1px 线 | 舞台光、书脊的高光与投影、期限表是一张有层级阴影的卡、到馆凭条是有色表面 |
| 物件 | 无 | 四本书脊立在书架上（书色取自封面），快到期的那本被抽出一截、夹着红书签；带打孔缺口的取书凭条；预约队列 |
| 运动 | 一处宽度过渡 | 首屏编排（标题揭开、日期去模糊、书脊依次立起）；按钮可按压；续借时期限端点用 FLIP 弹过去、斜纹段从左长出、新日期章"啪"地盖下、剩余天数滚动 |

v2 的 `src.html` 是源文件（`/*MOTION_CSS*/` 与 `/*MOTION_JS*/` 两处占位），`index.html` 是把 `assets/motion.css`、`assets/motion.js` 内联后的成品。

做 v2 时渲染后才发现、已写回 skill 的问题：

1. 动效库的注释里有字面的 script 结束标签，内联后脚本被截断——而入场动画先把内容藏起来，于是整页空白。→ `motion.js` 改了注释；`motion.css` 加了 `.no-motion` 失败保护。
2. 书脊既要参与入场（`transform`），又要被"抽出"（也是 `transform`），后者被入场的终态覆盖掉了。→ 状态位移改用独立的 `translate` 属性（`motion.md` 第 9 节）。
3. 竖排书名放在 flex 容器里会被折成两列、而且倒着读。→ 竖排文字用绝对定位加 `white-space: nowrap`（`typography.md`）。
4. 暗色下卡片顶边的白色高光太亮。→ 高光值也要随主题变（`visual-craft.md` 第 4 节）。

第二轮细节打磨（同样已写回 `references/visual-craft.md` 第 9 节）：中文眉题从等宽改无衬线；书名不拆行；元信息改用间距分隔；深色舞台里焦点环换浅色；凭条缺口与撕线共用一个变量；最后一本书斜靠在书立上；点书脊跳到对应行时那一行闪一下；去掉没用到的字重；入场触发改为"上沿进入"，修掉 1100×760 下首屏里的一块空白。

# 冷启动样例（`cold-start/`）

三个不知道任何背景的 Opus 5.5 子代理，只拿到一句用户请求，自己调用本 skill 做出来的成品（没有目视检查的条件，按 skill 的规定如实写了"未目视"）。每份附 `process.md`：读了哪些文件、立场句、被否掉的方向、贯穿装置、判据的逐条证据，以及它们认为 skill 里含糊或矛盾的地方——这一轮迭代就是按这些反馈改的。

| 目录 | 题目 | 贯穿装置 | 值得看的地方 |
|---|---|---|---|
| `01-landing` | 开源向量数据库官网 | 一根按 p99 耗时分层的岩芯（名字 Strata = 地层） | 抽象产品怎么找物件；地层色贯穿五处；资源账本数据逐项自洽 |
| `02-mobile` | 宠物医院预约小程序首页 | 一本手机里的宠物免疫证：疫苗贴纸、爪印章、空格 | 物件既是装饰也是数据；三家医院共用一把时间尺的排班 |
| `03-game` | 蒸汽朋克塔防的关卡选择与升级 | 整座城是一面钟：时针标进度、分针跟焦点；升级是两根送汽管道 | 强调色等于世界材质时焦点怎么处理；键盘与手柄的两级切换 |

渲染后看到、已写回 skill 的问题：贴纸叠压盖住日期（"不完美不能遮住信息"）；"黏住的叙事"里未激活步骤用 35% 透明度，读成坏掉的文字（改为降一级颜色）。

## 跨媒介校样

[返修台账](bench-queue.html)用鼠标、方向键或触控切换工单，筛选、清除或改变状态。[金工图形研究](metal-study.html)用同一件胸针在全形、轴端与展开之间切换。[翻花鼓](festival-beat.html)用空格或点按击鼓，按键和计分共用同一个节拍时钟。

[砾湾工坊](pixel-kit/project.godot)可用 Godot 4 打开。左右方向或十字键预览，Enter／A 装备，Esc／B 取消。「更换资源包」与「界面放大」同时影响宿主和附加组件。可运行 `godot --headless --path examples/pixel-kit --script res://verify.gd` 重放手柄、鼠标和主题缩放。

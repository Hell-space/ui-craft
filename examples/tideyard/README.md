# 潮汐修船坞

用 Godot 4 打开 `project.godot` 后按 F5，也可在此目录执行 `godot --path .`。工程自带四张像素图，首次运行即可进入栈桥。

方向键或 WASD 移动。走近橙色把手时，按 E 或空格操作绞盘。桥面落平后可以走到对岸。F2 收起或恢复渔具、挂布与小艇，F3 在日光和暮光间切换。

## 场景怎么做的

- 船台和工棚分居通道两侧。远港的吊车、厂房和水线压在接近的明度内。栈桥的浅色前缘一直延伸到新鲜木茬，升起的桥板可在右岸看到。
- 左岸绞盘上的橙色摇柄、右岸滑轮和两者之间的缆绳说明了机械关系。桥板转过约 79°，落平后才连接两段栈桥。
- `layout.json` 中的断岸轮廓供绘图脚本和脚下通行检测共用。绞盘、人物与小桥由 Godot 实时绘制。明暗切换使用两套像素图，两个时段的路沿、门灯及操作把手各自保留亮度。
- `tools/paint_harbor.py` 是船坞分层像素图的绘制源文件。安装了 Pillow 的 Python 可重新绘制 `art/` 中的四张 PNG。原生画布为 640 × 360，窗口等比缩放。

## 输入回放

```sh
godot --headless --path . --fixed-fps 60 --script res://verify.gd
```

回放依次尝试走向断口、远程操作、放桥、在桥上靠近侧缘、走到右岸、返回收桥。升起与落平分别组合杂物、照明四种状态，逐点比较 640 × 57 个脚下坐标。带显示设备运行时，可在命令末尾传入 `-- 输出目录` 保存 GPU 输出帧、原生画布和回放结果。

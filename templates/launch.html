你问

把调价条款写成一个函数

输入首年月租、年涨幅和封顶，算出每年的月租，方便和房东对数字。

Meridian 2 · Python

def rent_by_year(first, rise, cap=None, years=5):
    # 每年按 rise 上调；有封顶时单年涨幅不超过 cap
    r = min(rise, cap) if cap else rise
    return [round(first * (1 + r) ** y) for y in range(years)]

rent_by_year(86000, 0.08)            # [86000, 92880, 100310, 108335, 117002]
rent_by_year(86000, 0.08, cap=0.05)  # [86000, 90300, 94815, 99556, 104534]

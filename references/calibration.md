# 工具密度与排印校准

这里保留两种实作样本中的尺寸和组件比例。需要给没有设计系统的界面试一个起点时，可从相关表格取值。项目有自己的字体、密度和平台约定时，优先用邻近组件对照。以真实数据反复比较时，行距、数字对齐与筛选后定位通常比大标题更值得精调。

## 1. 在哪里建立辨识度

反复对照工单时，密度、基线和稳定的选择态可以体现产品身份。研究工具也可以有鲜明的图形语言，例如由真实信号画出的波形。品牌档案若供人逐件比对作品，同尺度的安静陈列可能比强烈的品牌色更合适。先放入真实内容，在读者最常停留的位置决定值得精做哪一处。

## 2. 高频工具的一组样本值

```
字体      一个无衬线家族通吃：Inter（cv11, ss01）/ IBM Plex Sans / Instrument Sans / 系统字体
          等宽：JetBrains Mono 或同族 Mono，用于 ID、时间戳、代码、快捷键
正文      13–14px / 20px 行高 / 400；中文后台 15px
标题      栏标题 14px/600 · 页标题 20–22px/600/-0.015em · 卡片标题 15px/600
次要      12px/16px · 12.5px 可用于活动流这类"比正文轻一点"的文字
画布      oklch(0.974 0.005 80)     暖纸灰，不是纯白也不是冷灰
表面      oklch(0.995 0.002 80)     工作区比画布亮一级
线        L 0.905（分隔）/ L 0.83（输入框、次按钮）
文字      L 0.235 / 0.435 / 0.53    三级，靠明度拉开
强调色    一个。钴蓝/蓝紫 oklch(0.48–0.53 0.15–0.16 262–264) 是它在工具里的实际选择
圆角      4（键帽、code）· 6（按钮、输入、菜单项）· 8（卡片、菜单）· 12（面板）· 14–16（弹窗）
间距      4 8 10 12 16 20 24 28 40
控件      28 工具栏 · 32 后台默认 · 36 表单 · 44 触屏
行高      列表行 38px · 表格行 40–48px · 侧栏项 32px
侧栏      宽 228–240 · 项高 32 · 项内边距 8 · 图标 16 · gap 8 · 分组间距 16–24
顶栏      48px，底边一条线贯通各栏，形成一条视觉地平线
暗色      画布 0.17 · 表面 0.205 · 抬起 0.24；边框 rgba(255,255,255,.08 / .14)
          文字 0.935 / 0.75 / 0.64；强调色 L 提到 0.68–0.74、C 乘 0.8，按钮改"浅底深字"
```

导航占了内容的注意力时，可压低次要入口的字号、彩度或面积。若任务本身是跨工作区切换，保留导航里足以定位的选中态和项目身份。

## 3. 编辑排版的一组样本值

```
字体      衬线负责声音：Newsreader（有光学尺寸轴，一个家族撑起全部层级）；中文思源宋体
          无衬线负责功能：Inter 或系统黑体
          等宽负责元数据：JetBrains Mono / IBM Plex Mono
正文      应用 14–15px；阅读 17–19px / 1.58–1.6；中文 16–17px / 1.75–1.95
标题      h1 clamp(40px, 6vw, 72–88px) / 1.0–1.08 / 400–450 / -0.022~-0.028em，max-width 13–18ch
          h2 32–48px / 1.08–1.2 / -0.018em
          中文大标题：思源宋体 600–900，字距 +0.06~0.14em，行高 1.08（竖排）到 1.3
眉题      等宽 11–12px / 500 / 全大写 / +0.06~0.08em / 次要色；中文用加空格的两字标签
纸        #F5F2EB        （观测范围 #F2ECE1 – #F7F5F0）
卡面      #FFFDF8        比纸亮一档，不是纯白
下沉面    #EEEAE0
墨        #1E1B17 / #524C44 / #6E675B
线        #E4DED3 / #D2C9B9；另有 1px 实墨线表示"栏目从这里开始"
强调色    从题材里取一个低彩的：L 0.41–0.56、C 0.06–0.14（配方见 tokens-paper.css）
圆角      印刷感 2px 通吃；一般 4 / 6 / 10；移动端卡片 18、图标底 11
阴影      零，或只给"浮在纸上的窗口"：0 1px 0 rgba(墨,.04), 0 12px 32px -12px rgba(墨,.18)
区块间距  clamp(88px, 11vw, 144px)；栏目标题到内容 56px
容器      1200px；正文行宽 30–36em；标题列与正文列 4:7 或 5:6 的比例分栏
暗色      暖炭灰 #171512 / #1E1B17，不是蓝黑；墨 #ECE5D8；强调色提亮到 L 0.71–0.77
```

纸墨的结构靠**线和明度**，不靠卡片：统计数据、安全条目、茶单表头都用一根 1px 的墨色顶线起头；分区用深一档的纸色。全页可以有**一个**反相区块（墨底、纸色字）来标记最重要的那一段。

## 4. 六个组件的实例

这就是"对"的样子。数值可随语域微调，结构不变。

```
按钮（主）
  height 32–36 · padding 0 12–14 · radius 6–8 · 13–14px / 500 · gap 6 · icon 16
  background var(--accent) · color var(--accent-fg)
  box-shadow: var(--shadow-button)          ← 一点"可按"的质感：贴底影 + 1px 内高光
  hover: 背景深一级，120ms · active: translateY(0.5–1px) · loading: 保持宽度，文案换进行时
  focus-visible: outline 2px, offset 2px（或"2px 底色间隔 + 2px 焦点色"的双环）
  disabled: 凹槽底 + 淡字（实底按钮用 opacity .5 也可以；叠在彩色或图像上时不可以）

按钮（次）
  同尺寸 · background var(--surface) · border 1px var(--border-strong) · color var(--text)
  hover: background var(--surface-sunken)，或边框再深一级

输入框
  height 与按钮相同 · padding 0 10–12 · radius 6–8 · 14px（移动端 16px）
  border 1px var(--border-strong) · hover: 边框加深
  focus: border var(--accent) + box-shadow 0 0 0 3px color-mix(in srgb, accent 20–26%, transparent)
  label 13px/500 在上方 6px · help 12–13px 次要色在下方 6px
  错误：边框换危险色，提示文字带图标并说明怎么改

卡片
  padding 20–24 · radius 10–12 · 二选一：1px border；或 var(--shadow-card-ring)
  标题 15/600 → 描述 14/次要色，间距 4 → 内容间距 16
  可点击：hover 只把 border 从 --border 变到 --border-strong，150ms。不抬起、不加阴影。
  只有营销页的大卡片可以 translateY(-2px)。

浮层（下拉 / popover）
  radius 8–10 · padding 4 · 项高 32 · 项 padding 0 8 · 项 radius 5–6
  box-shadow: var(--shadow-2)               ← 环 + 两层负扩散投影；暗色下环是亮描边
  入场 160ms var(--ease-out)：opacity 0→1, scale .97→1, translateY -2→0；退出 100ms 只做 opacity
  transform-origin 指向触发器；关闭后焦点还给触发器

表格
  表头 36 高 · 12px/500 次要色 · 与所在列同向对齐
  行高 40–48 · 只有横线 · hover 行给极淡的底
  首列是主键（主文字色）；ID 用等宽、可放在名称下作副行
  数字列右对齐 + tabular-nums；选中行 = 强调色浅底 + 左侧 2px 竖条
```

三个处处用得上的小配方：

```css
/* 负外边距保住对齐线：文字与上下的标签对齐，hover 底色向外扩 */
.value-btn { padding: 4px 8px; margin-left: -8px; border-radius: 6px; }
.value-btn:hover { background: var(--hover-overlay); }

/* 导航滚动后才出现底线，首屏不多一条无意义的线 */
.nav { border-bottom: 1px solid transparent; transition: border-color 200ms, background-color 200ms; }
.nav.scrolled { border-bottom-color: var(--border);
  background: color-mix(in srgb, var(--bg) 80%, transparent); backdrop-filter: blur(12px); }

/* 栅格列一律 minmax(0, 1fr)，否则长内容会把列撑开、在窄屏产生横向滚动 */
.grid { display: grid; grid-template-columns: repeat(12, minmax(0, 1fr)); }
```

## 5. 数字的排印

要比较的数字先确定单位、精度和基准，再决定它的视觉重量。

- 会变化、纵向对齐或并排比较的数字用 `tabular-nums`，孤立的静态大数字用比例数字（逗号不被撑开），并先确认字体有 `tnum` 特性（表格、计时、余额、指标带用等宽；首屏孤立的一个大数字用比例）。
- 大数字：28–48px、500–600、字距 −0.02 到 −0.035em、行高 1。
- **单位、货币符号、小数部分**降到主数字的 0.5–0.6 倍字号，改用次要色；`¥` 可轻微上移对齐。
- 涨跌：用语义色的**文字**，不用实底徽标；前面加 ▲▼ 或 + / −。减号用 `−`（U+2212）。
- 每个指标写明对比基准（"较上周一"），不放孤立的数字。
- 表格数字列的表头也右对齐。
- 精度以真实数据和单位为准。并排比较时对齐小数位，整数计数保持整数。
- 正文里的年份可用旧式数字（`oldstyle-nums`），表格与标签用等高等宽数字。
- 中文里：叙述用中文数字（"第三泡"），测量用阿拉伯数字（"45 秒"）。

## 6. 调整哪一处

| 观察到的现象 | 可以试的改变 | 回到哪里检查 |
|---|---|---|
| 时刻表只能逐行找车次，列间距相同却对不上读数 | 固定关键数字的基线，压缩低频字段。手指点按区可比可见内容更大 | 最长站名与异常延误同屏，确认仍能沿列比较 |
| 大字、满版色或材质抢走了用户真要辨认的东西 | 调主体占比、图文取景或相邻的明暗面。保留已确认的品牌色 | 远读主次与近读细节，分别看图和正文 |
| 常用工具缺少身份，原生控件已经清晰 | 试从数据、工序或工作对象选择一个有用的表现，例如给音频片段保留按时长绘制的轮廓 | 切换对象后它还能解释新的内容；焦点和键盘行为跟宿主一致 |
| 原来的控件比例只在某一设备合适 | 以当前字号、触控命中区、窗口缩放和真实内容选密度；可在同一界面为不同任务用不同尺度 | 用受影响设备查看最拥挤状态，操作后能回到所选对象 |

本页前面的两套尺寸是可复用的样本。已有产品产生的问题若只来自一处列宽或断行，直接处理那一处。

## 7. 验证密度

用实际视口并排看默认状态和最拥挤状态。选一行数字与所在列头，确认能连续比较。用键盘换行或打开详情后返回，确认还找得到刚才的对象。缩窄时先保住名称、结果和当下动作，其他信息可用渐进披露。字体回退会改变字宽，可在禁用网络字体后复核长名称。

缺少渲染工具时，仍可核对令牌、数据、布局约束和输入逻辑。现有素材或设计方向可以继续使用。向用户说明哪些结论还欠实屏检验。视觉评审方法见[审视与修正](critique.md)。

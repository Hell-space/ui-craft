# 产品宣传官网

当读者需要看清一件东西、理解一项功能或比较两种状态，先选能回答这个问题的画面。Apple 式产品叙事的尺度来自对产品细节的把握。单张主图、一个可信的局部和一次能解释变化的交互，已经能构成一页。

## 选镜头

| 读者想知道 | 适合的画面 | 运动如何提供证据 |
|---|---|---|
| 产品长什么样、比例如何 | 三分之四整机照保留轮廓、接触影和使用方向。穿戴产品用人体呈现尺度 | 首帧就能辨认产品。若需要交代厚度，让同一物件转到侧面后停住 |
| 看不见的零件如何协作 | 同一相机下的外壳、核心、底座，或有依据的截面图 | 保留一层作为参照，沿实际装配方向依次移开其余层。在分离处就近标名称 |
| 一项软件功能改变了什么 | 同一份真实输入的前后状态。沿用产品自己的画布、选区、光标和结果 | 锁住共同坐标，只移动对比边界或改变结果区域。最终数值或成品保持可读 |
| 不同材质或细节怎样挑 | 同一机身与照明下的表面处理，或两张能看清零件的微距 | 由用户主动切换。颜色选择保持角度一致，微距切换同时给出相应的部件说明 |

可把三个镜头记在草稿里，每个写清“要看见什么、靠哪个细节证明、停在哪儿”。规格表或购买入口放在读者做决定的位置。没有真实购买流程时，导航到规格、对比或演示即可。

## 构图与素材

- 先做一张完全静止的首屏。标题给产品名或一句具体结论，保留能辨认产品的一条完整轮廓。让软箱反射讲金属曲率，让侧光讲织物纹理，让真实的选区和处理结果讲软件的能力。
- 整机、特写、使用场景各换一次观察距离。相邻两节可以由明转暗，换景的理由来自新的观察任务。例如浅色看轮廓，深色看拆开的层，回到自然光看微距。已有品牌的底色和排印优先。
- 标题、正文、控件各有清楚的光学尺度。桌面可从 72–120px 的短西文标题、44–76px 的章节标题、17–22px 的导语起稿。中文按词组断行，长产品名允许换行。手机重新选取景范围，让手势、接缝或针尖仍然可见。字体与取景的实际决定以渲染为准。
- 优先采用用户的产品照片、模型和界面截图。概念产品可用实物模型或明确的几何、材质与灯光做常规三维渲染；没有产品图或模型时，可用现有细节、规格排印或功能演示组织主视觉。需要拆层时从同一机位输出相同尺寸、相同原点的透明图，保留装配锚点。只有一张主图时，改做整体到局部的焦点推近。没有结构资料时，选用户能验证的外观或功能。实拍和渲染素材依照各自的使用许可。
- 短标题旁边的留白可以留着。每个眉题、序号、标签和句子都要承担辨认、解释或操作的工作。重复产品名、重复标题含义的口号和无操作含义的胶囊可直接删除。

## 编排能被打断的动作

示例页用原生滚动驱动一个连续镜头。前段先抬起唱片，中段转盘离开底座，末段名称随着对应零件停稳。滚回任意位置都回到同一构图。浏览器保留原有滚轮、触屏、空格、PageDown、锚点和返回行为。

```html
<section data-scroll-scene aria-labelledby="assembly-title">
  <div data-scene-pin>
    <h2 id="assembly-title">驱动主轴</h2>
    <p>取下转盘后，底座中央的主轴可见。</p>
    <!-- 可访问的图或界面片段，完整静态构图位于进度 1。 -->
  </div>
</section>
```

```css
[data-scroll-scene] .cover {
  --lift: clamp(0, calc((var(--scene-progress) - .15) * 1.6), 1);
  transform: translateY(calc(var(--lift) * -38%));
}
```

脚手架已带 `Motion.scene(section)`。它把章节自己的滚动范围映射到 `--scene-progress` 的 0–1。用 `--scene-travel` 调整镜头停留距离。给需要吸附的直接子元素加 `data-scene-pin`。把裁剪放在图像容器里，让吸附祖先跟随文档滚动。组件按需挂载时调用 `const dispose = Motion.scene(section)`，卸载时调用 `dispose?.()`。

场景静止时无需持续绘制。主动画由图层的变换或透明度承担，文字首帧可读。减少动态效果、脚本不可用或视口放不下整个镜头时，直接排出可读的终帧。长页只加载首屏关键图，其余图给出固有宽高并按需加载。超过一张图就能解释的成本时，再考虑逐帧序列、视频或实时 3D。

## 前后对照与共同放大

先选读者能自己指认的地方，例如叶柄末端或叶缘缺口。用同一份输入和取景，把变化落在那一处。演示配准时，两层用相同的颜色、线宽和叠色方式贯穿前后。说明重合处的显色，允许单看固定稿。默认分界应露出两道错开的轮廓，拖过同一处就能复查。若演示本身是调色，则让色彩变化，固定素材与取景。清稿服务展示交付物时，直接给读者看实际交付的净稿。

“全幅”需要能检查原稿的四边。用目标宽度看四角和边缘标记，连同图例、分界手柄、圆角一起检查。局部模式让两层同时推近同一个地标，移动分界使它先后经过两侧，再回全幅定位。宣传特写可以裁满画面，用“叶缘细节”等名称交代取景。

可从 `python scripts/scaffold.py --type compare --out product/` 起稿。银杏例用同一幅线稿模拟两次扫描，固定青蓝稿，将朱红稿平移并旋转 2.75°，按配准结果复位，用同一叠色方式输出两张图。替换素材时，`media/registration-reference.webp` 是单看的固定底稿，`registration-before.webp` 与 `registration-after.webp` 是同画幅的前后叠印。同步更新图像宽高、图例与特写位置。只有两张成品图时可直接用下方的双图结构。

原生范围输入支持鼠标、触屏、方向键、Home 和 End。下例使用 2000 × 1300 的素材，换图时把比例改成新素材的宽高。禁用脚本时显示固定的等分对照。组件按需挂载时用 `Motion.compare(board)`，卸载时调用返回的清理函数。

```html
<div data-compare data-before-label="处理前" data-after-label="处理后" style="--compare-ratio: 2000/1300">
  <img data-compare-after src="media/after.webp" alt="处理后，同一处笔迹的重影已对齐">
  <img data-compare-before src="media/before.webp" alt="处理前，笔迹有两条错开的轮廓">
  <span data-compare-grip aria-hidden="true">↔</span>
  <input type="range" min="0" max="100" value="50" aria-label="左右对照分界">
</div>
```

## 使用与验收

```bash
python scripts/scaffold.py --type showcase --out product/
python scripts/shot.py product/index.html --browser "允许的浏览器可执行文件路径" --scenes
python scripts/scaffold.py --pack product/index.html
```

普通目录里的 `media/` 可直接替换。脚手架附的是虚构唱机 Orbit T1 的原创渲染与示范规格，新项目换成自己的内容。单文件会内嵌 `img`、`source`、`video` 的本地 `media/` 素材引用，包含 `srcset` 和 `poster`。已有项目可用 `--type showcase --bundle 目录/` 取得色彩、组件和动效库，按现有框架组织镜头。

安装了 Playwright 的环境可用 `--scenes` 保存宽屏和手机的起点、中点、终点、回滚截图，并检查减少动态效果。对照模板会另外测试 Home 和 End，截出完整的前后画面。并排看关键帧，确认镜头确实揭示了产品信息。也可在允许的浏览器中手动完成下表。

| 在浏览器里实际检查 | 看什么 |
|---|---|
| 1440 宽、常见笔记本和 375 宽各看首屏 | 标题、轮廓与主操作之间留有空间。窄屏也能辨认特征，文字没有覆盖操作点 |
| 章节停在起点、中点、终点，回滚到同一中点 | 固定参照可辨认，层次确实变化，标注跟着部件走，换向没有跳帧或残影 |
| 从最终画面滚出，使用导航跳过整个章节 | 松开吸附后可自然读到下一节，跳转无需等待镜头播完 |
| 触屏点选和键盘切换特写 | 焦点清楚，选择和图文一致，快速连续切换也落在最后一次选择上 |
| 拨到两端看纸边，再让分界扫过同一个细节 | 两端能看清各自的完整原稿。固定层的位置稳定，切换叠层显隐后能找回同一笔迹 |
| 切换系统减少动态效果；用 `--motion system` 生成的页面应呈现静态终帧。另禁用脚本重载 | 完整结构和结论仍可读，章节没有空白滚动距离，原生操作仍可用 |

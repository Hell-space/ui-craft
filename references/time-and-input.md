# 操作、判定与剪辑

先找决定观看顺序的人。访客可以停下、回看、跳到下一项。玩家还要把一次输入和判定连起来。无声短片的观众只能跟着剪辑走；确立地点、动作、人物与字幕的先后，就改变了他能理解的内容。静态海报把同样的顺序压在一页的尺寸、位置与距离里。

下面的同题取样来自 Claude Code 的 Opus 5.5「超高」。它为一座夜间公共天文台给出了三个不同的主决定。表中是维护者据此提炼的用法。

| 读者的动作 | 成品如何让这件事成立 | 怎样检验 |
|---|---|---|
| 手机上比较几场观测，再选择 | 场次以时间对齐，余位和售罄留在各自那一行，当下可选、当前已选和确认结果都有文字或形状线索。题材氛围可放在不挤占比较区域的地方 | 在目标窄宽度与长内容下查看几个候选。用实际支持的输入往返选择，确认结果指向同一场。售罄状态可读 |
| 移动中调整望远镜方向 | 观测缝建立方向，环的轮廓把目标从背景分开。接近正确方位时环逐渐清晰，进入判定范围才给读数，离开时反馈随状态解除 | 由同一侧接近、短暂停留、反向离开。对照准星、目标和实际判定，静音或减少动效后仍有形状线索 |
| 观看一段无声叙事 | 用穹顶开合把地点变成正在发生的事。动作完成后切到眼睛贴近目镜，轴线和视线接得上。末尾才给开放时间 | 按交付帧率播放整段，再看关键切点的前一帧、后一帧以及缩略画面。若字幕必须与播报同步或承担操作提示，出现时机应随任务改变 |

**反例决定适用范围。** 把开放时间压到网页末尾才揭示，会耽误正在选场次的人。游戏里若在对准时强行切到眼睛特写，玩家会失去方位。白昼修理站可以用深色工具的负形和橙色挂签夺回注意力；保留的可以是对齐、因果或视线方向，夜色和暖光各自重新决定。实际片长、色板、字体和镜头数取决于交付，范例中的 12 秒与第 8 秒切点只属于这段短片。

**交付范围决定证据。** 一张视频静帧可评取景、标题遮挡和人物轮廓。给出片段才能判断转场、动作衔接及字幕驻留。静帧中看出的改善可以直接交付，时间判断注明待验证条件。任务需要制作或导出视频时，本技能提供视觉与时序判断，沿用项目指定的制作与导出流程。图像工具限制同样适用。

若简报要观众先信一种解释，再看明白发生了什么，可在第一镜裁掉原因，在第二镜让它入画。两镜保留一处看得见的同一特征，让观众能把新解释接回刚才那件事，例如缺了一角的翼尖。若展项循环播放，任务又要求随时看懂传动，分别从每个镜头进入，沿各个施力点走到结果。两根杆同时入画也可能彼此重叠。首看顺序未知且简报未指定悬念时，两种剪法都可以先保留。

# 场景配色与素材校样

复合画面里的“素材像坏了”，常出在两件各自画对的东西接在一起时。先指出位置和误读，例如“右下的玩家头盔像装在货车前轮上”。分别处理画面里的关系、渲染器里的行为和作者可以选择的风格。墨绿色的排除范围按[技能入口](../SKILL.md)执行。

## 定色时看相邻的材料

在同一镜头中挑出环境占面积最大的两三块、被辨认的物件、玩家操作后的反馈。用真实图形铺色，先隐藏纹理和全屏调色。一辆涂漆的车、粗布篷和纸箱受同一片阳光，也应能靠受光面、高光宽度、折角或边缘硬度区分。盐原可以有白壳、阴面和磨开的土路；把天空、地面、车漆和火花都染成同一层旧黄色，会掩去这些差别。近白、钴蓝和暖黄只是这次校样的配方。

看三处实际交界。远处建筑会不会吞掉货物的顶线？刀头在最亮的天空和最暗的车体前都能辨认吗？与它相关的轨迹是否能指回操作者？需要追踪的对象可以共用局部颜色，也可以共用刀形、断续线或运动节奏。海报可以让货车先被看到，开战后则要在运动中找到小艇。潜行、沙尘和双色印刷可以刻意压缩色域，关键动作仍应有符合玩法的线索。

## 素材进场之后

| 眼前的问题 | 可执行的修改及验法 |
|---|---|
| 两个对象像同一个零件 | 在目标裁切中单独显示两者的剪影，再叠回去。轮胎与头盔、旗杆与远处风机、物品图标与角标若只碰一条边，可留出一条持续可见的背景缝，或让前物明确遮住后物一部分。保留遮挡时看得出完整前沿与中断后沿。分别看封面裁切、战斗镜头和最窄屏。 |
| 载具像悬浮、投影随转身倒向另一边 | 脚底、轮胎接点先落在同一地面；悬浮载具可以留出有高度依据的间距。区分紧贴接点的暗部和朝灯光反向延伸的投影。光源固定时，镜像角色、翻转图标或旋转精灵不能顺手翻转世界光向。固定镜头、光源和锚点，只换朝向，再单看阴影层。多光源或随屏幕打光的图标按其设定处理。 |
| 轨迹像系绳，腾空零件像没装好 | 从手、发射口或轮轴的局部坐标取得挂点，再跟随平移、旋转与缩放。飞出的物体在离手、飞行、返回各停一帧，核对效果的起止、前后层和身体边缘。带绳工具可以有连续实线，已经脱手的刃可以留空档、头尾粗细或方向提示。 |
| 放大能看清，实际画面像一团 | 单看对象、放回场景、关掉纹理各看一次。把纸纹、粒子、装饰描线按材料或景深分配。给必要轮廓和关键状态留位置。小尺寸若仍要读一串小字、铆钉与光点才能认出角色，需要重新组织大轮廓。 |

## 固定取景复验

先留原帧，制作一份仅动颜色的校样，再固定色板检验遮挡、光向或特效。这样能发现哪些问题调色无法消除。灰阶缩图可检验明暗与轮廓，回到彩色看材料和信号。若问题出在运动，重播同一输入、同一镜头下的几帧。截图里看不见敌人、材质边缘发白或护目镜接到车轮，只能说明这一帧的观感；敌人是否缺失、碰撞穿模或透明边像素异常需要运行或分层取证。

换成网页仪表盘时，固定同一组数值、位置和选择，再轮换明暗主题。检验轨迹所用的“能否顺着线找到发起者”也能用于图表直接标注与选中反馈。

同样的方法适用于 mod 的物品图标、网页产品转台和装备预览。宿主支持翻面、缩放或暗色背景时，直接在那些状态下复验。[白盐急递的原图与两步校样](../evals/evidence/saltline-art-study.webp) · [两次独立评稿和验证记录](../evals/saltline-art-review.md)

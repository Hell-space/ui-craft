# 通用视觉判断

## 先看作品要怎样被读

打开用户提供的内容、原图或当前界面。先用一句具体的话说明观众在什么条件下要认出什么。候选方向有实质差异时，可以用同一份内容做两个很小的灰度构图，在原尺寸验证后选一个。局部修正通常直接沿用已有方向。

| 场景 | 决定构图的事实 | 可以落到画面上的选择 |
|---|---|---|
| 展厅演出海报 | 路过者先读演出名，靠近才查时间地点 | 让演出名形成远读轮廓，演期独占稳定的对齐线，说明文字留在近读区。墨色版画、单色排字或摄影都可以成立 |
| 音频编辑器 | 使用者反复对齐同一段声音，波形不能在操作时乱跳 | 让文件、选区、读数共用时间基准。控制条克制，数值可键入；独立撤销一次已提交编辑 |
| 儿童节奏游戏 | 玩家在移动中判断下一个拍点 | 给拍点稳定的空间轨道与鲜明的形状。击中反馈短促，成功后立即露出下一拍；菜单才使用更丰富的插画 |
| 战术背包 | 玩家要判断能否装备、哪件已装、退回哪里 | 物品、焦点、装备标记分别承担不同信息。重点放到物品轮廓与比较结果，背景材质给游戏世界提供辨识度 |
| 研究数据界面 | 人要跨列找差异，长标签与单位会改变阅读速度 | 共用基线和小数位，用空白与少数分隔线形成组。低频说明跟随真实指标，颜色保留给有意义的异常 |
| 图标或品牌系列 | 同一身份需要跨多个尺度辨认 | 从剪影、内部负形、端点与笔画重量建立亲缘关系。先试实际最小尺寸，再决定可保留的纹理与细节 |

游戏项目可按[角色、场景、动作与道具的美术判断](opus-game-art.md)选择做法；非游戏视觉项目看同页的跨介质取舍。

用[跨媒介取舍](cross-medium-direction.md)比较同一条建议在哪些项目成立，又在哪些项目需要反过来。

## 把审美的分歧变成可检查的决定

- **主次**。眯眼、缩略、短时间扫视后，首先出现的块面应对应观众此时的问题。最重要的对象可以靠位置、孤立、清晰度或运动获得注意；面积只是一种手段。游戏 HUD 的视觉重心往往属于可玩世界。
- **亲疏与节奏**。同一件事在空间上靠近。段落、分组和章节之间给出更明显的停顿。网格藏在对齐线里，破格的边缘要有一个可读的参照。
- **形与字**。对齐字面和视觉重量，考虑标点悬挂、图形重心、数字跳位与中文换行。按最终物理尺寸看最细的一笔和最密的一行。标题字的个性不能牺牲读数辨识。
- **颜色与材质**。先分配明暗角色，再决定色相与饱和度。区分品牌色、材料色、数据编码与操作信号。背景已经很花时，优先稳定关键轮廓和文字附近的对比。材料能讲出对象的来历时才值得画。
- **动与静**。画面里有连续变化时，留一个固定参照。速度与手势、距离和频率相称。观众静静阅读时可完全静止。静态交付用裁切、尺度和留白表达时间顺序。
- **风格迁移**。对参考作品记录观察和作用。例如“同一硬件以三种观察距离出现，第二张专门说明接缝”。把观察带到新题目里，用新题目自己的素材验证。品牌规定的色值、游戏美术系统和作者的字形选择优先。

## 看成品，再作具体修改

印刷品先记成品的物理尺寸、预期视距和最小文字。可用相同视角作屏幕模拟，例如预期观众在 3 米处看 A3 竖幅，在约 60 厘米的看屏距离，把预览的实际宽度调至约 59 毫米。近读时再用尺把屏幕预览调至接近成品尺幅，分区检查日期、场地、细线与网点。屏幕像素密度和缩放会改变物理大小，交代实际检验介质。实际纸张、油墨和现场光线用打样判断。

在 [《候潮》屏幕校样](../examples/poster-distance.jpg) 中，远读靠题名字面和潮位标杆形成轮廓。近读检查发现地点偏轻、天空网点盖过远岸；加大地点字重并收细网距后，两处信息都保住了。这是针对这张 A3 海报的选择。

维持相同的内容与状态比较两版。视觉问题应指得到对象，交互问题应重做得出输入。例如“暂停菜单关闭后焦点落在背景按钮”“封面缩到书架尺寸时副标题和作者名抢同一层”。分别回到状态归属、光学对齐或字号层级上修。一个已能安静完成目标的画面可以交付。

## 系列作品并排与拆开时

观众既要看出这些作品出自同一套，也要能说出眼前这件有什么独到之处。找一处能反复出现的形或排字关系，再从每一件的内容里找出能改变那种关系的动作。原作中，访谈页的一笔高亮把判断连回引文，潮汐长文的曲线取自文内公式，计时器里的汤色随浸泡而变。换去另一个题材时，可以沿用这种因果，重新决定用字、墨块、留白或取景来表现。[访谈页原作](../specimens/01-landing-saas/notes.md) · [潮汐长文](../specimens/06-editorial/notes.md) · [茶计时器](../specimens/08-free/notes.md)

若作品会被拆卖、打乱或单独收藏，先取出最容易认混的两件，各自按实际分发尺寸显示。暂时盖住题名，看还能指出哪一处在相遇、转弯、分离或停下。恢复题名，再查它在真实列表里能否读出。若只能靠排列顺序辨认，就将决定含义的接点、缺口或负形移进单幅。细纹和材料细节仍可留给大图。缩略图来自大图导出时，要看实际缩下来的图；随容器重排的网页还要看小容器本身。

一笔动势线也会改变观众对物件的解释。画到接近闭合时，看它是否已被读成套在物件外的一根绳；表示弹出时，在最终尺寸看起点、离开的方向和逐渐拉开的间隙。做成一套的三张可以分别采用初稿或修稿里更清楚的那一笔，字位、用色和其他已有效的部分继续沿用。[逐张匿名评稿](../evals/series-study.md#植物展签的独立改稿)

缩略图还要看它在什么地方出现。列表已列出曲名时，封面可以把空间让给脚步渐远的节奏；听众只能靠图按名点选时，把同一个落字位置做成小尺寸题签，必要时减掉它将遮住的图层。在《回层》的试稿中，井顶放大才读得出两个字，代价是少了几圈楼梯纵深。印刷整套仍可保留原取景。[80 像素题签实拍](../evals/evidence/cover-player.png)

当委托要让人展开整幅再沿线阅读时，拼回真实顺序，看跨缝的线能否从同一高度沿原方向走下去。两种用途并存时，可以重新分张，也可以保留版幅，移动画里的事件。比如让铁路跨过折缝，把分岔和两支刚刚分开的空隙留在《道岔》那张。再查相邻封面四角有没有多出一小截无从解释的线。若路线来自真实地图，就保住原始数据，移动取景或安排独立局部图。[Opus 评过的两种取景与修稿](../evals/series-study.md#同一条铁路的两种用途)

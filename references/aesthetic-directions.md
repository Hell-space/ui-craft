# 审美方向

这份词汇表用来辨别方向。先从 [视觉判断](art-direction.md) 找内容、载体和使用条件的依据，再选合适的字形、色温、密度与动势。纸墨、工具和品牌作品等既有样本可供对照。

直接从下表挑一个套上去，只比不做选择好一点。最好的方向来自题目本身（见文末"如何得到一个原创方向"）。

## 方向的六个旋钮

任何视觉方向都可以拆成六个参数。定调就是给每个旋钮一个明确的位置，并让它们互相印证。

| 旋钮 | 一端 | 另一端 |
|---|---|---|
| **字体** | 中性无衬线（隐身） | 有性格的衬线/展示字体（发声） |
| **色温与彩度** | 冷、低彩、单色 | 暖、高彩、多色 |
| **密度** | 疏朗、大留白 | 紧凑、信息密集 |
| **几何** | 直角、细线、硬边 | 大圆角、粗线、柔边 |
| **深度与质感** | 纯平、无阴影 | 层叠、阴影、纹理、材质 |
| **动效** | 几乎静止 | 丰富、有弹性 |

**内在一致性**是关键：直角硬边配弹跳动效、奢华衬线配高饱和撞色，这类互相矛盾的组合会让界面显得没想清楚。（有意的反差是高级手法，但只在一个旋钮上做，其余保持一致。）

## 十二个方向

### 1. 瑞士网格（International / Swiss）

**气质** 理性、客观、清晰、永不过时。
**适用** 信息密集的内容站、机构官网、设计工具、文档。
**字体** 一款 grotesque 无衬线贯穿始终（Switzer、Inter、Hanken Grotesk、Schibsted Grotesk）；层级靠字号与字重的强烈对比。
**色彩** 黑、白、一个纯正的强调色（红、蓝、或黄）。
**几何** 直角或极小圆角；细线；严格的列栅格，元素对齐到网格线。
**质感** 纯平，无阴影。
**动效** 极少，线性或标准缓动。
**标志性手法** 超大号标题与小号正文的悬殊对比；不对称构图；用编号、细线和留白组织信息；左对齐到同一条线。
**易犯的错** 没有栅格纪律就只是"朴素"；标题不够大就没有力量。

### 2. 暖调极简（Warm minimal）

**气质** 安静、从容、有人味。
**适用** 写作与笔记工具、个人站、生活方式品牌、面向个人的 SaaS。
**字体** 人文气质的衬线做标题（Newsreader、Instrument Serif、Source Serif 4），干净的无衬线做界面（Figtree、Instrument Sans）。
**色彩** 米白、暖灰的纸张色底；深棕黑文字；一个低彩度的暖色强调（陶土、赭石、橄榄）。
**几何** 中小圆角（6–10px）；细边框。
**质感** 极轻的纸张颗粒；几乎没有阴影。
**动效** 柔和缓慢的淡入。
**标志性手法** 宽松的行高与页边距；正文字号偏大；装饰极少，全靠排版。
**易犯的错** 太淡太素而缺少焦点——仍需要一个明确的记忆点（比如一个很大的衬线标题）。

### 3. 专业工具暗色（Pro tool dark）

**气质** 专注、高效、精密。
**适用** 开发者工具、设计软件、项目管理、命令面板、任何长时间使用的生产力应用。
**字体** 中性无衬线（Geist、Inter）13–14px；等宽字用于数据、快捷键、ID。
**色彩** 深色表面分三到四层（L 0.14–0.24），带微弱的冷色相；一个明亮的强调色；文字三级明度。
**几何** 小圆角（4–8px）；1px 半透明白边框；紧凑控件（28–32px 高）。
**质感** 表面的顶部内高光；微妙的径向光晕；阴影很少。
**动效** 快（100–180ms），克制，注重键盘操作的即时响应。
**标志性手法** 键盘快捷键提示（`⌘K` 样式的小键帽）；命令面板；极细的分隔线；高信息密度下的严格对齐。
**易犯的错** 对比不足导致发灰；强调色用得太多；为了"酷"牺牲可读性。

### 4. 技术等宽（Technical / mono）

**气质** 工程感、透明、极客、诚实。
**适用** 开发者产品、API 文档、基础设施、开源项目、个人技术博客。
**字体** 等宽字承担标题或界面标签（JetBrains Mono、Geist Mono、Commit Mono、IBM Plex Mono），配一个无衬线读长文。
**色彩** 近黑或近白底；终端式的强调色（琥珀、绿、青），只用一个。
**几何** 直角；1px 实线或虚线边框；看得见的网格与标尺。
**质感** 点阵、网格、ASCII 图形、扫描线（很淡）。
**动效** 打字机、光标闪烁、逐字显现——只用在一处。
**标志性手法** 代码块作为主视觉；用 `[ ]`、`//`、`→`、`└─` 等字符做装饰；标签写成 `key: value`；显示版本号、坐标、时间戳等"元数据"。
**易犯的错** 全用等宽字读长文很累；做成黑客帝国式的陈词滥调。

### 5. 杂志编辑（Editorial）

**气质** 有文化、有叙事、讲究。
**适用** 内容产品、品牌故事、作品集、报告、长文、高端营销页。
**字体** 高对比的展示衬线做大标题（Fraunces、Playfair Display、Cormorant、Zodiak、Boska），耐读的文本衬线或无衬线做正文。
**色彩** 纸色底加黑字，一个强调色；或大胆的整版色块。
**几何** 直角；细线（发丝线）分栏；多栏布局。
**质感** 大幅摄影或插画；首字下沉；引文放大。
**动效** 很少；图片的缓慢显现。
**标志性手法** 超大斜体衬线；期刊式的页眉（刊号、日期、栏目）；不对称的图文穿插；大号引语；正文分栏；图注。
**易犯的错** 没有好图片时很难撑住——改用大字排版作为主视觉；正文行太长。

### 6. 新粗野主义（Neo-brutalism）

**气质** 直接、叛逆、有趣、不装。
**适用** 创意工具、年轻品牌、个人项目、活动页、需要强烈辨识度的产品。
**字体** 粗重的 grotesque 或有怪癖的展示字体（Space Grotesk、Bricolage Grotesque、Cabinet Grotesk、Clash Display）。
**色彩** 纯白或米黄底、纯黑描边，加两三个高饱和的平涂色（柠檬黄、亮粉、电光蓝）。
**几何** 粗黑边框（2–3px）；直角或刻意的大圆角；硬阴影（无模糊的偏移色块 `4px 4px 0 #000`）。
**质感** 纯平色块；可有贴纸、手绘元素。
**动效** 干脆的位移——按下时元素"压进"阴影里。
**标志性手法** 硬阴影；故意的错位与旋转（±2°）；超大字；裸露的结构。
**易犯的错** 颜色失控；可读性牺牲过头；不适合需要建立信任的严肃产品。这是少数可以合理使用纯黑纯白的方向。

### 7. 柔和有机（Soft / organic）

**气质** 亲切、平和、关怀。
**适用** 健康、冥想、育儿、教育、面向大众的消费应用。
**字体** 圆润友好的无衬线（Manrope、Plus Jakarta Sans、Outfit、DM Sans）；或圆头字体。
**色彩** 低彩度的柔和色（鼠尾草绿、雾蓝、燕麦、淡桃），明度接近，对比温和（但文字仍须达标）。
**几何** 大圆角（16–28px）、全圆按钮；有机形状、不规则圆。
**质感** 大而软的弥散阴影；柔和的同色系渐变；手绘感插画。
**动效** 缓和、带轻微弹性。
**标志性手法** 色块之间的柔和过渡；充足的内边距；大而友好的触控目标。
**易犯的错** 过于甜腻幼稚；对比不足；所有东西一样软而失去层级。

### 8. 精致奢华（Refined luxury）

**气质** 稀缺、讲究、不急不躁。
**适用** 高端消费品、酒店、珠宝、建筑事务所、精品电商。
**字体** 纤细优雅的衬线（Cormorant、Instrument Serif、Bodoni 一类）做标题，小号、宽字距的全大写无衬线做标签。
**色彩** 极度克制：黑、象牙白、一个金属或宝石色点缀（香槟金、群青、酒红），面积极小。
**几何** 直角；发丝线；大量留白。
**质感** 高质量摄影是主角；细腻的材质感。
**动效** 慢而顺滑（400–700ms），淡入、缓慢的视差。这是少数适合较长时长的方向。
**标志性手法** 极大的留白；小而精的文字；全大写宽字距的导航；图片出血；价格和按钮都很低调。
**易犯的错** 金色渐变和花体字是廉价的"伪奢华"；真正的奢华感来自克制和比例。

### 9. 复古活泼（Retro / playful）

**气质** 怀旧、乐观、有个性。
**适用** 消费品牌、播客、游戏周边、餐饮、活动。
**字体** 有年代感的展示字体（厚重衬线如 Young Serif、Gloock，或圆润的复古无衬线）。
**色彩** 一个年代的色盘：七十年代的芥末黄、焦橙、橄榄绿、奶油白；或八九十年代的霓虹与粉彩。
**几何** 圆角、拱形、条纹、放射线、波浪。
**质感** 印刷颗粒、轻微的套色错位、半调网点。
**动效** 有弹性、有趣，但数量少。
**标志性手法** 色块叠印；徽章与印章形状；重复的图案条带。
**易犯的错** 元素堆砌成大杂烩——选定一个年代并保持纪律。

### 10. 东方留白（East Asian restraint）

**气质** 含蓄、沉静、有余韵。
**适用** 中文与日文产品、茶、文创、出版、文化机构、追求格调的本土品牌。
**字体** 宋体/明朝体做标题（思源宋体），黑体做正文；西文配人文衬线。可少量使用楷体或仿宋作引文。
**色彩** 取自传统材料：宣纸白、墨黑、黛蓝、朱砂、石青、茶褐、竹青。低彩度为主，朱砂之类的亮色只作一点印章式的点缀。
**几何** 直角或极小圆角；细线；可用竖排文字作标题或侧标。
**质感** 纸纹；留白本身就是内容。
**动效** 缓慢淡入，如墨晕开；极少。
**标志性手法** 大面积空白与小而精的文字形成张力；竖排；印章式的红色小方块；用编号（壹、贰、叁或 01、02、03）和细线分节；不对称的"偏"构图。
**易犯的错** 堆砌水墨、祥云、仿古纹样变成"景区风"；现代的东方感在于比例与留白，不在于符号。

### 11. 数据密集（Dense data）

**气质** 高效、权威、一切尽在掌握。
**适用** 交易终端、监控面板、运营后台、分析工具、表格型应用。
**字体** 紧凑清晰的无衬线（Inter、IBM Plex Sans）12–13px；数字用等宽或 tabular。
**色彩** 中性为主；语义色承担大量工作（涨跌、状态、告警），因此必须严格调校并保持一致；强调色极少。
**几何** 小圆角或直角；细线分隔；紧凑行高（28–32px）。
**质感** 纯平。
**动效** 近乎没有；数值变化时短暂高亮。
**标志性手法** 表格是主角；迷你图（sparkline）嵌入单元格；固定表头和首列；键盘导航；多面板可调整大小。
**易犯的错** 密度变成拥挤（靠严格对齐和层级避免）；语义色过饱和变成圣诞树；为了"好看"加大留白反而损害效率。

### 12. 当代先锋（Contemporary / experimental）

**气质** 前卫、自信、艺术化。
**适用** 设计工作室、时尚、文化活动、作品集、想要与众不同的品牌页。
**字体** 把字体当图像用：极端字重、极端宽窄、可变字体动画、超大号裁切出画面。
**色彩** 意想不到的组合，或极端的单色。
**几何** 打破栅格：重叠、旋转、出血、非矩形。
**质感** 噪点、模糊的色团、扭曲、混合模式。
**动效** 是设计的核心部分：光标互动、滚动驱动、字体变形。
**标志性手法** 一个大胆的概念贯彻到底。
**易犯的错** 可用性崩溃——导航和关键信息仍须清楚可达；实验性留给展示层，功能层保持常规。

## 如何得到一个原创方向

上面十二个是常见的落点。更好的做法是从题目本身推导：

**1. 从题目里提取具体的东西。** 这个产品所在的世界里有什么材质、物件、场所、年代、印刷品？
- 给烘焙坊做订单系统 → 牛皮纸、手写价签、面粉的白、烤箱的暖光。
- 给气象数据工具做面板 → 等压线、航海图、仪表刻度、冷调的蓝灰。
- 给独立书店做网站 → 书脊的排列、借书卡、铅字印刷、纸张的黄。

把这些具体的东西翻译成旋钮位置：牛皮纸 → 暖褐底色加纸纹；手写价签 → 一处手写体点缀；等压线 → 细线底纹。

**2. 混合两个方向。** 取一个方向的结构配另一个方向的表皮：瑞士网格的骨架加复古的色盘；数据密集的布局加暖调极简的字体与颜色。交叉处往往有新意。

**3. 把一个旋钮拧到极端。** 其余保持克制，只让一个参数走到头：极大的字、极小的字、极窄的栏、只用一种颜色、完全没有圆角、完全没有边框。极端的那一处就是记忆点。

**4. 借一个界面之外的参照。** 一张唱片封面、一份机场的导视系统、一本药典、一张老地图、一台合成器的面板。参照物越具体，细节的决定越容易。

**5. 做一个"反面"版本。** 这类产品通常长什么样？反过来：金融产品通常冷蓝严肃，试试暖色与衬线；儿童产品通常五彩缤纷，试试克制的双色。前提是反得有道理。

## 避免收敛

收敛本身不总是坏事——**新意是有预算的**。工具和数据界面应当刻意收敛到一套验证过的默认值，只改强调色与密度；品牌页和营销页才需要每次重新出发。

已知的吸引子（Opus 5.5 自己点名的），选中任何一个都要写出理由：

1. Inter + zinc 冷灰 + 靛蓝 `#4F46E5`
2. 米白 `oklch(0.98 0.01 80)` + 陶土 `oklch(0.6 0.13 40)` + Instrument Serif / Fraunces 标题 + 等宽眉题
3. 近黑 `#0A0A0A` + 荧光绿/青强调 + Geist Mono
4. 居中 hero + 点阵底纹 + 顶部径向光晕 + 带边框截图
5. 三列"图标 + 标题 + 两行描述"特性卡

拿不准时，同一内容换一种组织方式再看。例如摄影集可以按时间连续铺图，也可以给单件作品足够面积并留一个索引。若两版只换了主题色和字体，它们回答的仍是同一个构图问题。先检查设计与产品的真实关系；当常见模式最支持任务时，可以直接使用。详见[审视与修正](critique.md)。

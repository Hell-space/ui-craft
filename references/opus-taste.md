两轮新增的[超高实机与跨产品评稿](../specimens/09-interview/cross-medium.md)将这里的样本偏好置于相反的任务中对照。选新方向可直接看[跨媒介的视觉取舍](cross-medium-direction.md)。

## 1. 这份画像是怎么来的

- **八个界面样本**：让 Opus 5.5 在不带任何风格提示、不使用任何 skill 的条件下，各做一个题目——SaaS 落地页、电商运营后台、issue tracker、移动端记账、中文茶品牌官网、长文页、组件样张、自由发挥——并写下每个决定的理由。原件在 `specimens/01`–`08`（每个含 `index.html` 与 `notes.md`）。
- **一份审美自述**：让它在不读任何文件的情况下回答一组关于自己偏好的具体问题。原件在 `specimens/09-interview/taste.md`。
- **一份评审**：让它读完本 skill 的旧版本后指出与自己不一致、缺失和太泛的地方。原件在 `specimens/09-interview/skill-review.md`。
- **统计与目视**：对八个样本的字体、颜色、圆角、阴影、动效做了提取统计，并逐个渲染查看。

局限要说清楚：只有八个样本、同一时段、它做的时候没有渲染工具（凭推演完成）。这是一份有证据的画像，不是定论。下文凡写"观测到"的是样本里实际出现的，写"自述"的是它自己说的，两者不总是一致（见第 7 节）。

## 2. 一句话与四个来源

它自己的话：

> 美的界面，是每一个像素都"有理由在那里"，并且这种理由能被眼睛直接感到，而不需要被解释。

气质上它偏好**安静、紧凑、精密、有一点点温度**——"像一本排版很好的技术书、一把做工好的工具，而不是一张海报"。

它认为美来自四处，按它实际看重的顺序：

1. **克制带来的秩序。** 规则的数量要少于眼睛能读出的数量：一两款字体、三四个字号层级、一个强调色、一套间距倍数。廉价界面的问题几乎总是规则太多。
2. **对比的精确。** 美不是柔和，而是该强的地方非常强、该弱的地方非常弱。平庸界面的症状是一切都"中等"。
3. **材质的诚实。** 屏幕是发光的平面，所以它喜欢接近"印刷品加极轻微的物理感"：1px 发丝线、几乎看不到的阴影、纸一样的底色；不喜欢假装成玻璃、塑料或霓虹。
4. **内容先于装饰。** 好界面去掉所有装饰后依然成立。真实的数据、真实的文案、真实的长度，比任何插画都更显高级。

在自由发挥的样本里它又补了两点：**与真实事物的一致**（"视觉不是贴上去的，它来自被表达的东西本身"），以及**节奏**（"大与小、密与疏、静与动之间的落差，让眼睛有路可走"）。

## 3. 它怎么开始：立场句、被否掉的方向、贯穿装置

这是它与"照着规范做"最不一样的地方，也是八个样本里最稳定的模式。

### 3.1 一句"是 X，而不是 Y"的立场

每个样本都从一句话开始，而且这句话是通过**否定该品类的默认长相**来定义的：

| 题目 | 立场句 |
|---|---|
| 运营后台 | "一份晨报，而不是一面监控墙。" |
| 茶品牌 | "一本印出来的茶册，而不是一个电商首页。" |
| 记账 App | "安静的纸本账簿"——像一本好用的本子，而不是每次打开都对你喊叫的仪表盘 |
| 落地页 | "研究者的笔记本 + 编辑出版物" |
| Issue tracker | "安静、密、可以整天开着的工具" |
| 茶计时器 | "像一张放在茶盘边的卡片，而不是一个 App" |
| 组件系统 | "安静的工具，带一点材料感" |
| 长文 | "安静的科学期刊 + 纸面感" |

"安静"出现了五次。这是它的底色。

### 3.2 写下三四个被否掉的方向

每份笔记都有"考虑过又放弃的方向"，每条带理由。被否掉的几乎总包含**这个品类最常见的样子**：记账 → 深色霓虹金融卡片风、首屏大环形图；后台 → 黑底大数字的指挥中心、每个 KPI 一张卡；茶品牌 → 水墨留白禅意风、朱红印章色、黑底金字；B2B 落地页 → 深色科技风加渐变光晕、对话气泡插画。

它不是为了求异，理由都落在使用场景上（"它让钱看起来像游戏积分""每天看的东西，装饰会很快变成噪音""它回避信息——用户真正想知道的是这泡茶是哪个坑的、什么火、多少钱"）。

### 3.3 先确定"这一屏只回答哪一个问题"

> 先确定"这一屏只回答哪一个问题"，然后让最大的那个元素回答它。

记账首页最大的数字不是总资产也不是本月支出，而是"本月还可以花 ¥4,113.60"，紧跟着换算成"剩 21 天，平均每天可用 ¥195.89"。运营后台的主角不是数字而是一段用人话写的摘要：昨天怎么样、离目标差多少、今天先做什么。

### 3.4 一个从题材里长出来、能承载信息的"贯穿装置"

每个样本都有一个贯穿全页的概念，而且它**同时是视觉符号和信息编码**，不是装饰：

- 记账：**节奏线**——月份过去了三分之一，所以总预算条和每个分类条上都有一根竖刻度标在 33.3% 处，不用算就能看出"购物用了 71% 而月份才过 33%"。
- 运营后台：年度进度条上一根**时间进度刻度**，并直接写出"落后 ¥31 万"。
- 落地页：**荧光笔**——既是品牌符号（logo 下那道黄）、又是交互隐喻（引文被"划出来"）、又是视觉锚点。
- 茶计时器：**茶汤的颜色**——浸泡时由淡变浓，逐泡变淡；记录里每一泡的色点保留当时的颜色，"记录本身就是一条渐变"。
- 茶品牌：每个颜色对应一个实物——锈红来自丹霞岩壁、冷灰蓝只属于水、炭火橙只出现在焙火一节。
- 组件系统：状态色以釉料命名并取色（青瓷、赭石、铁红、天目）。
- 长文：标题下那条细线是用真实潮汐公式算出的十四天潮位。

规律：**颜色、图形、动效，每一样都对应题材里一件真实的东西**。找不到对应物的装饰，它不加。

## 4. 两种语域：纸墨与工具

八个样本落在两种语域里。它们共用同一套底层习惯（见第 5 节），区别在表层。

### 4.1 纸墨（六个样本：落地页、后台、记账、茶品牌、长文、茶计时器）

像印刷品。用于内容、品牌、消费类，以及"每天读一次"的数据页面。

| 角色 | 观测范围 | 典型值 |
|---|---|---|
| 纸（页面底） | L 0.94–0.97，C 0.007–0.016，H 83–89 | `#F5F3EE` `#F6F3EC` `#F7F5F0` `#F3EFE6` `#F2ECE1` |
| 卡面 | 比纸亮一档，不是纯白 | `#FFFEFB` `#FFFDF8` `#FAF7F1` |
| 下沉面 | 比纸深一档 | `#EFECE5` `#EFEADF` `#E9E1D2` |
| 墨（主文字） | L 0.22–0.25，暖 | `#1E1A16` `#1B1A17` `#1E1D1A` `#23201B` |
| 次墨 | L 0.39–0.45 | `#57504A` `#4A473F` `#5C5549` |
| 辅墨 | L 0.55–0.62 | `#8C847A` `#7A7568` `#8E8574` |
| 线 | L 0.84–0.92，常分两档 | `#E4DFD6` `#DCD5C6` `#D5CABA` |
| 强调色 | L 0.41–0.56，C 0.06–0.14（低彩、偏土） | 铜 `#9A4A22`、锈红 `#9E4A2F`、琥珀 `#9A5B1E`、墨绿 `#2E6A4E`、松绿 `#2F5D50`、深海蓝 `#1D5266` |

- **字体**：一款有声音的衬线（Newsreader；中文用思源宋体 Noto Serif SC）加一款干净的无衬线（Inter 或系统黑体）加可选的等宽（JetBrains Mono / IBM Plex Mono，用于时间戳、编号、眉题）。衬线负责"声音"（标题、引文、大数字），无衬线负责"功能"（标签、按钮、表格）。
- **几何**：圆角小——印刷感最强的两个（茶品牌、长文）只有 2px；其余 6/10 或 4/8/12。
- **深度**：几乎没有阴影。层级靠"纸色与更亮的卡面"的明度差，加 1px 细线。
- **线的语法**：1px 墨色实线表示"一个栏目从这里开始"，1px 淡线表示次级分隔。
- **暗色**：暖炭灰（`#16130F` `#171512` `#161513`），不是蓝黑；强调色提亮到 L 0.71–0.77。

### 4.2 工具（两个样本：issue tracker、组件系统；以及它自述里的"惯性默认"）

像一件做工好的工具。用于整天开着的产品界面。

| 角色 | issue tracker | 组件系统 |
|---|---|---|
| 画布 | `oklch(0.972 0.004 85)` | `oklch(0.975 0.006 80)` |
| 表面 | `oklch(0.995 0.002 85)` | `oklch(0.995 0.002 80)` |
| 线 / 强线 | L 0.912 / 0.86 | L 0.895 / 0.80 |
| 三级文字 | `oklch(0.235 0.012 265)` / 0.45 / 0.60（冷墨） | `oklch(0.235 0.014 55)` / 0.43 / 0.565（暖墨） |
| 强调色 | `oklch(0.53 0.16 264)` 蓝紫 | `oklch(0.475 0.15 262)` 钴蓝 |
| 暗色底 | 0.165 / 0.19 / 0.235 | 0.175 / 0.212 / 0.245 |

- 画布仍然是**暖纸灰**（H 80–85，彩度极低），不是冷的 zinc——这一点和它自述的"冷灰惯性"不同。
- **字体**：一个无衬线家族通吃（IBM Plex Sans、Instrument Sans；自述里是 Inter），等宽用同族（Plex Mono）或 JetBrains Mono。组件系统里仍保留了 Newsreader 给页面标题和大读数——"有声音的时刻"。
- **基准字号 13–14px**，行高固定在 4px 网格上（13/20、14/20、12/16）。
- **圆角 4 / 6 / 8**（组件系统加到 12 面板、14 弹窗）。
- **用 OKLCH 写 token**（纸墨样本多用 hex）。
- **密度高**：列表行 38px，表格行 48px，控件 28/36/44。
- **一个强调色承担三件事**：选中、焦点、可提交。"这三件事在一个工具里是同一种'注意这里'。"
- **状态色只出现在 14px 的小图标上**，从不铺底色。
- 明暗两套都认真调过，跟随系统并可手动覆盖。

### 4.3 怎么选

它的原话是把"新意"当作预算：

| 题目类型 | 新意预算 | 它的做法 |
|---|---|---|
| 后台、工具、设置页、表单 | 低 | 默认值几乎原样使用，只改强调色色相与密度 |
| 文档、阅读 | 中 | 改正文字体（衬线）、行长、字号 |
| SaaS 落地页 | 中高 | 改强调色、标题字体、主视觉与文案 |
| 品牌页、活动页、作品集 | 高 | 默认值只保留间距与状态，其余从题目推导 |

> 工具 UI 好不好看，九成在执行精度，不在新意。

## 5. 标志性手法（十八条）

这些是跨样本反复出现的做法。括号里是出现它的样本编号。

**1. 数字是一等公民。** 样本里几乎所有数字都用了 `tabular-nums`（本 skill 的规则在此基础上细化为：会变化、纵向对齐或并排比较的数字用 `tabular-nums`，孤立的静态大数字用比例数字（逗号不被撑开），并先确认字体有 `tnum` 特性）；大数字收紧字距（−0.02 到 −0.035em）；**单位、货币符号、小数部分降到约一半字号并改用次要色**，"分是真实的，但不该和元抢注意力"。（01 02 04 05 08，全部八个都用了 tabular-nums）

**2. 用真正的排印字符。** 减号用 U+2212 而不是连字符；弯引号；数字与单位之间用不换行空格；em dash 两侧加细空格；标题里手动防孤字。（01 04 06）

**3. 颜色表达好坏，符号表达方向。** 退款率下降标绿——因为它是好事；涨跌永远配 ▲▼ 或 +/−，颜色不单独表意。（02）

**4. 多数状态不上色。** 记账里支出不标红——"绝大多数条目都是支出，全部染红等于全屏报警"；"今天"那根柱子始终是墨色——"今天还没过完，不该提前评判"。预警有阈值，避免每个分类都在变色。（04）

**5. 强调色只在有意义的时刻出现。** 茶计时器平时几乎单色，主按钮只在"出汤"那一刻变成琥珀色——"全页唯一一个彩色实心块，只在需要你动手时出现"。（08）

**6. 主按钮可以是墨色。** 当品牌色属于内容时（荧光笔黄属于"客户的话"），主按钮用墨黑，"而不是属于'买我'"。（01 05 08）

**7. 细线代替阴影，"影子线"代替描边。** 卡片常写成 `box-shadow: 0 0 0 1px 线色, 0 1px 2px rgba(暖色, .04)`——一圈 1px 的环加几乎看不见的贴底影；描边用 `inset 0 0 0 1px` 以不占布局尺寸。阴影带底色的色相（`rgba(60,50,30,.04)`、`#2a1d0d26`），从不用纯黑。（02 04 07 08）

**8. 浮层用"环 + 投影"。** `0 0 0 1px …/0.08` 的环形边框加多层、负扩散的投影；暗色下环换成亮描边。（03 07）

**9. 负外边距保住对齐线。** 可点的值、选中的列表项用负 margin 抵消自身内边距：文字与上下的标签严格左对齐，hover 或选中的底色向外扩，而不是把文字推开——"对齐线不因状态而移动"。（03 08）

**10. 小标签用字距和降一级的颜色，而不是图标。** 分区靠"12px、加宽字距、次要色"的小字。纸墨语域里常用等宽大写；中文里用加空格的两字标签（"茶 单""本 席"）。但在高密度工具里它反而回避全大写——"在工具里显得喊叫"。（01 05 06 08；03 相反）

**11. 栏目编号与重复的栏目骨架。** `01 / 本季茶单`、罗马数字小节号；全页每个栏目重复同一个"编号 + 标题 + 一句说明"的结构，"像书的版式"。（05 06 07）

**12. 图标自己画，状态图标编码含义。** 所有样本都是内联 SVG、1.3–1.6px 描边、没有一个 emoji。状态图标是"进度饼"（空环、半饼、四分之三饼、实心勾），优先级是信号条，紧急用不同的**形状**——色盲用户也能读。（03 02 04）

**13. 没有图片时，用排版、信息图和真实感的界面片段。** 落地页用 HTML/CSS 搭出可信的产品界面当主视觉；茶品牌用 SVG 画岩壁剖面、山场示意图、焙火时间线、出汤秒数图——"从岩茶本身的知识结构里长出来的信息图"；长文的两张图由真实公式算出。它明确不画"为了有图而画的装饰性插画"。（01 05 06）

**14. 假数据前后自洽，而且讲一个有张力的故事。** 每日之和等于已花、等于分类之和；摘要里的数字与下方模块一致；同一句客户引文在首屏、步骤、证据链里是同一条。数据带着日期语境（设定在双十一前一天）和轻微的问题（总体比节奏多花 ¥219.73，主要来自购物）。金额带分，不是 1000、2000 这种"整数感"。（01 02 04）

**15. 文案承担信息设计。** 标题写结论而不是栏目名；副标题写口径（"较上周一""已扣预售锁定""含预售定金"）；提示给出可执行的建议（"往后每天少花 ¥10 左右"）；错误信息告诉人怎么修；危险确认里取消按钮叫"Keep firing"而不是"Cancel"；下拉里不可选的项写明原因。（02 04 07）

**16. 诚实的小标注。** "位置示意，非实际比例"；"半岩"如实标注为非正岩；页脚不编造备案号；不放假评价和假 logo 墙；统计数字写明出处与时间窗口。可信感来自具体。（01 05）

**17. 一处表演性的动效，而且它在演示产品。** 落地页全页只有一个表演性动画——引文的黄色高亮从左向右划过，"它演示了产品做的事"。每天用的后台则明确没有入场动画："每天看的东西，动画第二天就是负担"。其余过渡 120–200ms。（01 02 03）

**18. 一点人的语气。** "茶是你的，不是表格的。""本月已记 37 笔"作为列表安静的终点。"每年只发两封"的订阅承诺。不多，每页一两处。（04 05 08）

另外几条小而稳定的习惯：焦点环的颜色有时与强调色分开，避免和"紧急"混淆（02）；禁用态用明确的凹槽底加灰字而不是 opacity（07）；键帽 `<kbd>` 底边 2px（03 08）；导航滚动超过 8px 才出现底线（01 05）；所有栅格列用 `minmax(0, 1fr)` 防止长内容撑破（01 05）；页面 `<title>` 随状态变化（03 08）；`localStorage` 用 try/catch 包裹（03 07）。

## 7. 它说的和它做的不一样的地方

把自述和样本并排，有几处明显的差异。使用这份画像时以**样本（做的）**为准，自述作为它"不特别用心时"的参考。

| 方面 | 自述 | 样本里实际做的 |
|---|---|---|
| 最常用的字体 | Inter，"坦白说过度使用了" | Inter 只出现 3 次且都是配角；主角是 Newsreader 与思源宋体 |
| 首选衬线 | Instrument Serif、Fraunces | 一次都没用；四次都选了 Newsreader（理由：有光学尺寸轴，一个家族撑起全部层级） |
| 默认强调色 | 靛蓝 `#4F46E5`，"我的惯性" | 八个里只有两个是蓝紫；六个是低彩度的土色或深绿 |
| 默认底色 | `#FAFAF9`（几乎白），冷灰 zinc 是惯性 | 明显更暖更深的纸色（`#F2ECE1`–`#F7F5F0`） |
| 进入缓动 | `cubic-bezier(0.16, 1, 0.3, 1)` | `cubic-bezier(.2, .7~.8, .2, 1)`，更柔 |
| 图标 | "只用 Lucide" | 全部手绘内联 SVG |
| 字号种类 | "一屏最多 4 个" | 后台样本用了十三种，含半像素值 |
| 颜色写法 | "用 OKLCH" | 六个纸墨样本用 hex |

合理的解读：自述描述的是它**不被要求时的惯性**（Inter + 灰阶 + 靛蓝，"Vercel/Linear 系"），样本是它**被要求当作署名作品认真做时**的结果（纸墨）。它自己也这么区分："前者是我的惯性默认，后者是我想做得更好时的默认。"

## 8. 它自知的偏见与吸引子

它对自己相当坦白。这些话值得原样保留，因为它们标出了这套审美的边界：

- **"太安全。"** "我的默认结果不会错但不令人记住。很多我做的界面看起来像同一家公司出品。"
- **"偏冷偏技术。"** "即使给消费品牌，我也容易做成开发者工具的气质。"
- **看不见图像带来的回避。** "缺少插画、摄影、独特版式这类'性格资产'，因为我无法真正看见图像，就倾向回避。"以及："在没有渲染反馈的情况下，我判断'做完'更多依赖心理模拟和规则核对，所以会偏向保守、可预期的方案。"
- **偏好英文语境的排版。** 中文场景下需要有意识地调整，否则会把负字距和紧行高带过去。

它点名了五个**吸引子**——模型不假思索时会滑进去的固定组合，"选中任何一个都要写出理由"：

1. Inter + zinc 灰 + 靛蓝 `#4F46E5`
2. **米白底 + 陶土橙 + 衬线大标题 + 等宽小眉题**
3. 近黑 `#0A0A0A` + 荧光绿或青 + Geist Mono
4. 居中 hero + 点阵底纹 + 顶部径向光晕 + 带边框的截图
5. 三列"图标 + 标题 + 两行描述"的特性卡

第 2 条需要特别注意：**它自己的八个样本有六个落在这个吸引子附近**（暖纸底、土色强调、衬线标题、等宽眉题）。它在评审里说："模型被'别用紫蓝渐变、别用 Inter'推开之后，最常落到的就是这一组，这已经是一眼可辨的新模板。"

这批样本经常使用纸墨与工具两种语域。[尺寸校准](calibration.md)保留了它们的实作数值。换一个题目时，可比较其中哪些选择仍服务于内容、哪些选择只是重复了作者习惯。

## 9. 它给另一个模型的指令（经观测校正）

它在自述里写了二十条"照着做就能接近我的审美"的指令。下面是保留其原意、并按样本里实际做的校正后的版本。

1. 先写一句"是 X，而不是 Y"的立场，并写下至少三个被否掉的方向——其中必须有这个品类最常见的样子。
2. 决定这一屏只回答哪一个问题，让最大的元素回答它。
3. 从题材里找一个能承载信息的贯穿装置；每个颜色、每张图都要对得上题材里的一件实物。
4. 底色不用纯白，文字不用纯黑。浅色用暖纸色（L 0.94–0.975），墨色 L 0.22–0.25 且带暖。
5. 文字三级：L 约 0.23 / 0.43 / 0.58。靠明度拉开，不靠透明度。
6. 整个界面一个强调色，面积不超过视口的 5%，只出现在主操作、选中、焦点和极少数关键数据上。需要警示色时另留一个，只在真正需要时出现。
7. 字体按语域选：纸墨用"衬线负责声音 + 无衬线负责功能 + 可选等宽负责元数据"；工具用一个无衬线家族通吃。两种字体之间必须分工明确。
8. 字重只用 400 / 500 / 600。500 是按钮、标签、数字的主力；衬线大标题用 400–450。
9. 字距随字号连续变化：≥48px −0.03em，24–36px −0.02em，18–20px −0.01em，正文 0，全大写小标签 +0.06 到 +0.08em。中文一律不用负字距，标题可加 +0.02 到 +0.1em。
10. 会变化、纵向对齐或并排比较的数字用 `tabular-nums`，孤立的静态大数字用比例数字（逗号不被撑开），并先确认字体有 `tnum` 特性；单位、符号、小数降到约一半字号并改用次要色；表格数字右对齐。
11. 分隔与容器用 1px 线；卡片要么无阴影，要么"1px 环 + 几乎看不见的贴底影"；真正的投影只给浮层，写成"环 + 多层负扩散"，颜色带底色的色相。
12. 圆角常用三级，外加一级给舞台、弹窗这类大容器（全圆胶囊、正圆头像、设备画框、数据图小色块不计）。印刷感 2px；工具 4/6/8；一般产品 6/8/12；移动端可到 11–18。
13. 间距只用 4 的倍数；组间距至少是组内的两倍；越大的语义断点留白越多。
14. 默认左对齐，所有东西对到同一条左边线；居中只留给节奏上的"停顿"（证言、最终 CTA、空状态）。
15. 按钮与输入框同高（工具 28/32/36，营销与触屏 44）；字号 13–14px、字重 500。
16. 每个交互元素有 hover、active、focus-visible、disabled；焦点环 2px、offset 2–3px；按下下沉 0.5–1px。
17. 动效：颜色与边框 120–150ms；浮层进入 160–200ms、退出更快；缓动 `cubic-bezier(.2,.8,.2,1)`；不写 `transition: all`；每天用的界面不做入场动画；营销页全页最多一处表演性动画，且它要在演示产品。
18. 图标自己画或用一套线宽一致的，1.5px 左右，`currentColor`，不用 emoji。状态图标用形状编码含义。
19. 假数据要前后自洽、带分带日期、讲一个有轻微张力的真实故事；文案写结论、写口径、写下一步，不写形容词。
20. 做完前：眯眼看焦点是否正确；数一数字号、灰、圆角的种类；删掉一个不影响理解的装饰；再看一遍 375px。能渲染就渲染出来看——它自己最大的遗憾就是"这次没有在浏览器里实际检查"。

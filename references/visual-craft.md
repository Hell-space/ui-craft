## 1. 观察表现力

| 手段 | 能帮助什么 | 试在何处 |
|---|---|---|
| 尺度与留白 | 让人看清主角，给相关内容一个阅读顺序 | 给插图保留整个剪影，把密集参数收在共用基线；纯排字也可用空白和重量成立 |
| 色面 | 建立辨识或明确分区 | 让工作区的中性色托住颜色有业务含义的对象，或以品牌色承载整幅海报 |
| 取景与材料 | 让人了解对象的形状、制造方法或用法 | 让实物全貌和一处接缝出现在不同尺度，同一取景里光源方向一致 |
| 图形与运动 | 让状态的来处、去处或变化被看见 | 对齐两次扫描的边缘，或直接显示调整后的读数。阅读时可以让画面安静 |

## 2. 按注意力分配手法

每天操作几十次的页面，把精度花在可扫读性、状态和反馈。浏览一件作品时，可以给它占整屏的空间。画面需要表现力时，先选一项真正能加强内容的手法。逐件添加纹理、发光、卡片、投影和入场会让这些手法互相抵消。

一屏版画可以只有纸面、印迹、题名和规格；工具的多个工位可以全部同等可见。两者的质量取决于要辨认的对象是否清楚、动作是否有位置。历史样例中的强度档位只说明当时的做法。

## 3. 色面：用大块颜色而不是到处点缀

面积跟颜色的任务走。交互信号在有大量数据的页面应清楚可辨，品牌画面也可以让一种颜色占据大片背景。

**深色 hero / 深色区段**：页面最重要的那一块用深色底（不是纯黑，带题材色相，L 0.18–0.30），上面的文字用纸色，强调色在深底上提亮。浅色页面里插一块深色区，是最便宜、最有效的"高级感"。

```css
.band-deep {
  --band: oklch(0.24 0.045 265);            /* 深靛，带一点题材色相 */
  background:
    radial-gradient(80% 120% at 85% 0%, oklch(0.36 0.08 265 / .55), transparent 60%),   /* 右上角的光 */
    radial-gradient(60% 80% at 0% 100%, oklch(0.30 0.06 30 / .35), transparent 70%),   /* 左下角另一色的余温 */
    var(--band);
  color: oklch(0.96 0.01 85);
}
```

**有色的表面**：卡片、面板不必是白的。用强调色的极浅调（L 0.94–0.97，C 0.02–0.04）做背景，同色相深调（L 0.30–0.40）做文字——像一张有颜色的纸。一页里两三种有色表面（同明度、不同色相）可以区分类别，比彩色图标优雅得多。

**双色调**：深色 + 一个亮色（比如石墨灰 + 柠檬黄、深海蓝 + 珊瑚），两者都有面积。适合品牌页。

**颜色从哪来**：仍然从题材来（见 `opus-taste.md` 第 3 节）。区别只是让它有面积。

## 4. 光与深度

屏幕上的"高级感"大半是光。设一个光源（默认左上方），然后贯彻：

**表面高光**：凸起的东西顶边亮一点。

```css
.raised {
  background: linear-gradient(to bottom, oklch(1 0 0 / .06), transparent 40%), var(--surface);
  box-shadow: inset 0 1px 0 oklch(1 0 0 / .5),            /* 顶边受光 */
              inset 0 -1px 0 oklch(0 0 0 / .04),          /* 底边背光 */
              var(--shadow-2);
}
```

**层级阴影（五档）**：每档由"贴地的接触影"加"远处的环境影"组成，颜色带底色色相，负扩散让影子集中在下方。

```css
:root {
  --shade: 30 20 10;   /* 暖底用暖影；冷底改 15 20 35 */
  --shadow-1: 0 1px 1px rgb(var(--shade) / .05), 0 1px 3px rgb(var(--shade) / .06);
  --shadow-2: 0 1px 2px rgb(var(--shade) / .06), 0 4px 10px -2px rgb(var(--shade) / .08);
  --shadow-3: 0 2px 4px rgb(var(--shade) / .06), 0 12px 24px -6px rgb(var(--shade) / .12);
  --shadow-4: 0 4px 8px rgb(var(--shade) / .06), 0 24px 48px -12px rgb(var(--shade) / .18);
  --shadow-5: 0 8px 16px rgb(var(--shade) / .08), 0 40px 80px -20px rgb(var(--shade) / .28);
}
```

卡片 1–2 档，hover 升一档；浮层 3 档；弹窗 4 档；作为主视觉的物件 5 档。

**有色投影**：强调色的实底按钮和物件，影子用它自己的颜色。

```css
.btn-accent { box-shadow: 0 1px 0 oklch(1 0 0 / .25) inset, 0 6px 16px -6px color-mix(in srgb, var(--accent) 65%, transparent); }
```

**环境光晕**：主视觉物件背后放一团大而淡的光，让它"站在舞台上"。光晕必须在一个物件**后面**——没有物件的光晕就是第 10 节里的廉价做法。

```css
.stage { position: relative; isolation: isolate; }
.stage::before {
  content: ""; position: absolute; inset: -20% -10%; z-index: -1;
  background: radial-gradient(50% 50% at 50% 55%, color-mix(in srgb, var(--accent) 22%, transparent), transparent 70%);
  filter: blur(20px);
}
```

**暗色里的光**：阴影几乎看不见，改用表面越高越亮、1px 半透明白边、`inset 0 1px 0 oklch(1 0 0 / .06)` 顶边高光。浅色里 0.6 的顶边白高光放到暗色里会变成一道刺眼的亮线——把高光写成随主题变的变量：`--hi: light-dark(rgb(255 255 255 / .65), rgb(255 255 255 / .05))`。

## 5. 材质

**颗粒**：大面积的色面和渐变上加 3–6% 的噪点，消除色带，并让屏幕显得像纸或胶片。

```css
/* 用一小块预先生成的噪点图片平铺（ui.css 的 .stage::after 里就有一份，直接复制那个 url）。
   不要用 SVG feTurbulence 滤镜现算，也不要加 mix-blend-mode：滚动到这里时它们要在 CPU 上重新计算、反复重绘，是常见的掉帧原因。 */
.grain::after {
  content: ""; position: absolute; inset: 0; pointer-events: none; border-radius: inherit;
  background: url("data:image/png;base64,…") 0 0 / 72px 72px;   /* 从 ui.css 复制 */
  opacity: .5;
}
```

**磨砂玻璃（做对的版本）**：只用在**下面确实有东西在动**的地方（吸顶导航、浮在图上的面板）。它很费性能：滚动时背后的内容每一帧都要重新模糊，一页最多一处，模糊半径 ≤ 12px；吸顶导航默认用接近不透明的底色就够了（ui.css 的 `.nav` 已经这样做，要毛玻璃时加 `.glass`）。四件套缺一不可：模糊、提饱和、1px 亮内边、顶边高光。

```css
.glass {
  background: color-mix(in srgb, var(--surface) 68%, transparent);
  backdrop-filter: blur(16px) saturate(1.6);
  box-shadow: inset 0 0 0 1px oklch(1 0 0 / .35), inset 0 1px 0 oklch(1 0 0 / .6), var(--shadow-3);
}
```

**光泽 / 金属**：一条斜向的线性渐变带（亮—暗—亮）模拟反光，用在徽章、卡面、实体按钮上，不超过一处。

**渐变描边**：1px 的边从亮到透明，像光沿着边缘走。

```css
.edge { border: 1px solid transparent;
  background: linear-gradient(var(--surface), var(--surface)) padding-box,
              linear-gradient(160deg, oklch(1 0 0 / .7), oklch(1 0 0 / 0) 40%, color-mix(in srgb, var(--accent) 30%, transparent)) border-box; }
```

## 6. 物件：把题材里的东西画出来

当实物或结构能解释内容时，可以采用原有产品照片、摄影棚渲染、实物扫描、插画、矢量或程序绘图。下面是适合用网页原生图形构建的例子。

| 题材 | 可以画的物件 |
|---|---|
| 图书、阅读 | 书脊（不同颜色、宽度、高度，竖排书名）、借书卡、书签 |
| 金融、记账 | 银行卡、收据（锯齿边）、钱包、存钱罐的刻度 |
| 出行、票务 | 登机牌（打孔虚线、二维码区）、行李牌、站牌 |
| 音乐、播客 | 唱片（同心圆纹理）、磁带、波形 |
| 天气、自然 | 天空渐变随时间变化、云、潮汐曲线、等高线 |
| 开发者工具 | 终端窗口、代码编辑器、提交图 |
| 任何 SaaS | 带真实内容的产品窗口（见 `layout.md`） |

物件要有**材质与光**：圆角、顶边高光、投影（第 4 节的 4–5 档）、可以轻微旋转（±2–6°）、可以叠放或扇形展开。最好**可交互**：hover 抬起、点击翻面、拖动。

物件上的小字（批号、章里的字、刻度数字）：要么是装饰——`aria-hidden`，可以低于字号下限；要么承载信息——那就按正常字号排，必要时把物件画大一点。材质的色阶（高光、中间调、暗部）写成一组变量。

物件的颜色仍然来自题材：书脊的颜色可以是每本书真实封面的主色（取暗调），这样一排书脊本身就是一条有信息的色带。再让这个颜色**贯穿到页面的其他地方**——期限表每一行的色条和进度线都用同一本书的书脊色，读者不用读字就能把书架上的书和表里的行对上。

完整的例子：`examples/library-v2-expressive/`（书架、书签、取书凭条、盖章动效），以及同一道题的平淡版 `examples/library-v1-flat/` 作对照。

## 7. 图形：从数据和题材生成，而不是贴装饰

- **生成式底纹**：等高线、同心圆、点阵、经纬网，用 SVG 画，透明度 4–10%，用 `mask-image: radial-gradient(...)` 让它在边缘淡出。它应该与题材有关（地形用等高线、声音用同心圆、海用波纹）。
- **数据即图形**：把页面的真实数据画成大的、好看的图形——一条横贯全宽的曲线、一个大环、一排比例条。数据图做大、去掉坐标轴、只留最关键的一两个标注，就是插画。
- **字即图形**：超大的数字或单字（200px 以上），裁出画面、描边、或被物件压住一角。中文单字（"茶""书""潮"）做主视觉非常有力。
- **SVG 线条描绘**：路径加 `class="draw"`，进入视口时被画出来（`motion.css`）。

## 8. 构图：几种总是好看的骨架

**物件 + 巨字**：左边超大的标题或数字，右边一个带光晕和 5 档投影的物件，物件压过栅格线。适合 3–4 档的首屏。

**深色舞台**：首屏整块深色，中间一个物件，背后环境光，标题在物件上方，下面一行小字。像发布会。

**色面切分**：页面纵向分成浅—深—浅—有色几段，每段一个主题，段与段之间不用线，只靠色面交替。

**有层级的 bento**：大小不一的格子，最大的那格（占 2×2）放主视觉物件或核心数据，其余格子各一个次要信息。每格可以是不同的有色表面。

**重叠与出格**：物件跨过两个区段的边界；大标题被图形压住一部分；卡片叠放有错位。前提是其余部分严格守栅格。

**节奏**随阅读动作决定。逐章揭晓的长页可以用面积或疏密提示转折。一组要并排比较或拆开识别的作品可以保留同一骨架，把变化交给每件作品特有的形与动作。[系列作品的取景](art-direction.md#系列作品并排与拆开时)

## 9. 抛光清单

以下来自带有实体质感的样本。先看哪一项能改善当前画面；扁平图形、密集工具与明确品牌体系各有自己的细节做法。

- 卡片、按钮、物件的顶边 1px 内高光；暗色里尤其重要
- 嵌套圆角同心（外 = 内 + 间距）
- 主按钮：有色投影 + 内高光 + 按压时缩到 0.97
- 数字：tabular-nums；单位小一半、淡一档；大数字收紧字距
- 图标：线宽随字重；与文字光学对齐（常需下移 0.5–1px）
- 文字：`text-wrap: balance` 给标题，`pretty` 给段落；中英之间留隙
- 焦点环：2px，与背景之间有 2px 间隔；颜色与强调色一致
- 滚动条：细、颜色跟随主题
- 选中文字：强调色 20%
- 图片与物件：1px 的内描边防止融进背景
- 分隔线：不通栏，从文字起点开始
- 加载：骨架屏形状与真实内容一致，内容到了用 200ms 交叉淡入，而不是跳出来
- 空状态：一个小物件插画 + 一句话 + 一个按钮，不是一行灰字

下面这些是做 `examples/library-v2-expressive` 时逐条修掉的，单个都很小，但每一条都会让人觉得"差一点"：

- **中文不用等宽字体排。** 等宽字给汉字之间留出过宽的空隙，眉题、小标签会显得稀散。等宽只给数字、编号、索书号；含中文的眉题用无衬线加 `tabular-nums`。
- **专名不拆行。** 书名、人名、地名、金额用 `white-space: nowrap` 包住，避免"《克拉拉与太 / 阳》"。
- **元信息片段用间距分隔，不用"·"。** `display: flex; flex-wrap: wrap; column-gap: .75em`，每段 `nowrap`。用"·"连接时，一折行就会在行尾悬一个点。
- **深色区域里的焦点环换成浅色。** 全局焦点色是强调色，放到深色舞台上几乎看不见：`.stage :focus-visible { outline-color: 纸色 }`。
- **异形物件内部的线与外形用同一个变量定位。** 凭条两侧的缺口和中间的撕线写成同一个 `--cut`，内容区用 `min-height` 保证不越线，否则两者一定错开几像素。
- **物件留一点不完美，但不能遮住信息。** 叠放的贴纸、章、卡片，露出的部分必须包含它承载的那条信息（日期、数字、名字）；叠压超过三分之一就该错开。精密题材的刻度与读数保持精确。最后一本书斜靠在书立上（`rotate: 4deg; transform-origin: 100% 100%`，间距算到刚好碰上书立顶端），日期章各自歪一点（−3° 到 2°）。全都横平竖直的物件像示意图，不像东西。
- **跳转目标闪一下。** 点书脊跳到对应行时，那一行用书的颜色淡淡闪 1.8s（`:target` + `scroll-margin-top`），读者知道自己落在哪。
- **舞台上的主按钮反白。** 强调色与舞台同色系时（绿舞台配绿按钮、红舞台配红按钮），按钮会融进背景；改用纸色底、舞台色字（`assets/styles.css` 里的 `--stage-btn`）。
- **单个静态大数字用比例数字。** `tabular-nums` 会把 1,284 的逗号撑成一个字宽；只有会变化、要对齐的数字才用等宽数字。
- **只加载用到的字重。** 网络字体每多一个字重就多一份下载，中文字体尤其大。
- **用真实的屏幕尺寸检查首屏。** 1440 宽看起来没问题的页面，在 1100×760 下可能有一块卡片上沿已进入首屏、内容却还没出现——入场的触发条件要按"上沿进入"算，而不是"露出百分之多少"（`motion.js` 已改）。

## 10. 什么时候这些手法会变成廉价

判据只有一条：**手法和题材之间有没有因果**。

| 廉价 | 同一手法的好版本 |
|---|---|
| 紫蓝渐变铺满 hero，什么都没放 | 深色舞台上有一个题材物件，背后是它颜色的光 |
| 每张卡片都是玻璃 | 只有浮在内容上方、下面有东西滚过的那一层是玻璃 |
| 发光描边、霓虹阴影 | 有色投影只给强调色的实体，强度 ≤ 65% |
| 满屏光晕球 | 一个光晕，在一个物件后面 |
| 每个区块都从下面飘上来 | 首屏编排一次；下面的区块只在第一次进入时轻微淡入 |
| 3D 插画人物 | 用 CSS/SVG 画的题材物件 |
| 渐变文字 | 实色的超大字，被物件压住一角 |

旧版 skill 把左栏全部禁掉了，连带右栏一起丢了。现在的规则是：右栏的每一样都可以用，**写得出它对应题材里的什么**。
